Expansion Cards & Peripheral Slot Subsystem

📖 Open Exhaustive Card Guide → 🎛️ Launch Slot & Card Studio

The Apple //c Ultra features a modular, hot-swappable 7-Slot Motherboard Architecture. Each slot decodes 16 dedicated I/O softswitch registers ($C080 + $n0), a 256-byte Slot ROM ($Cn00), and optional banked 2KB expansion ROM ($C800–$CFFF). Here is how each plugged-in card operates:

Slot 1: Printer $C090

ImageWriter II: Captures all PR#1 print output to a virtual tractor-feed paper console with 1-click text/PDF download.

BASIC: PR#1 : PRINT "..." : PR#0
Slot 2: Web MIDI $C0A0

MIDI Master: Transmits 31.25 kBaud MIDI note-on/off messages directly to connected USB synthesizers & DAWs via Web MIDI API.

BASIC / ASM: IN#2 / PR#2 / $C0A1
Slot 3 (or Any Slot 1–7): JS Sandbox $C0B0

Scriptable Card: Universal slot support! Write custom JavaScript handlers for ioRead(), ioWrite(), and romRead() and plug into ANY slot from 1 to 7.

I/O: $C080+(Slot*$10) / PEEK / POKE
Slot 4: Thunderclock $C0C0

ProDOS RTC: Supplies real-world host PC date & time to ProDOS file timestamps and clock routines at $C400.

Driver: $C400 ProDOS Clock
Slot 5: Mockingboard $C0D0

Dual AY-3-8910: 6-channel programmable audio synthesis & 6522 VIA timers for Ultima, Skyfox, and C# chiptunes.

Chiptunes: 6 Channels + Noise
Slot 5: Uthernet $C0D0

W5100 Ethernet: Hardware TCP/IP stack for BBS Telnet, Contiki OS, and retro networked multiplayer gaming.

Network: IP / TCP / Telnet
Slot 6: Disk II $C0E0

Floppy Drive: 140KB 5.25" floppy controller supporting 6-and-2 GCR encoding & 4-phase stepper motor logic.

Boot: PR#6 / Boot Disk
Slot 7: SmartPort HD $C0F0

32MB Hard Disk: 65,536 ProDOS blocks mapped to /HD with 1-click physical export to Floppy Emu & CFFA3000.

ProDOS: PR#7 / 32MB /HD
