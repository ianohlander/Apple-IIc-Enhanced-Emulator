# 65C02 CPU Core Reference

This document details the cycle-accurate CMOS 65C02 processor emulation implemented in [`src/emulator/cpu/CPU65C02.ts`](file:///h:/My%20Drive/Repos/Apple-II-Emulator/src/emulator/cpu/CPU65C02.ts).

---

## 1. Register Architecture

The processor maintains 8-bit and 16-bit registers:

| Register | Width | Description | Initial / Reset State |
| :--- | :--- | :--- | :--- |
| **A** | 8-bit | Accumulator for arithmetic and logical operations | `$00` |
| **X** | 8-bit | Index register X (address offsets, counters) | `$00` |
| **Y** | 8-bit | Index register Y (indirect indexed addressing) | `$00` |
| **SP** | 8-bit | Stack Pointer (points into page 1: `$0100-$01FF`) | `$FF` |
| **PC** | 16-bit | Program Counter | Loaded from `$FFFC/$FFFD` (default `$F800`) |
| **P** | 8-bit | Processor Status Register | `$24` (Expansion bit 5 set, Interrupt disabled) |

### Status Register (P) Bitmask Layout

```
Bit:   7   6   5   4   3   2   1   0
Flag:  N   V   1   B   D   I   Z   C
```

* **N (Negative, bit 7)**: Set if MSB of result is 1.
* **V (Overflow, bit 6)**: Set if signed two's complement overflow occurs.
* **1 (Expansion, bit 5)**: Always reads as `1`.
* **B (Break, bit 4)**: Distinguishes software `BRK` from hardware `IRQ` on stack.
* **D (Decimal, bit 3)**: Enables binary-coded decimal (BCD) mode for `ADC` / `SBC`.
* **I (Interrupt Disable, bit 2)**: Maskable interrupts (`IRQ`) ignored when set.
* **Z (Zero, bit 1)**: Set if arithmetic/logical result equals 0.
* **C (Carry, bit 0)**: Unsigned carry from arithmetic or shift/rotate operations.

## 2. Hardware Vectors

The CPU fetches execution addresses from top of memory on reset or interrupts:

| Vector | Address | Handling in Emulator |
| :--- | :--- | :--- |
| **NMI** | `$FFFA-$FFFB` | Non-maskable interrupt; pushes PC & P, vectors to ISR. |
| **RESET** | `$FFFC-$FFFD` | Cold/warm reset; resets SP to `$FF`, sets `I` flag, jumps to address. |
| **IRQ / BRK** | `$FFFE-$FFFF` | Maskable interrupt / Break instruction; pushes PC & P. |

## 3. CMOS 65C02 Instruction Extensions

Unlike the original NMOS 6502 (Apple II / II Plus), the Apple //c uses the CMOS 65C02, featuring bug fixes and instruction extensions:

### New Instructions

* **`BRA rel`**: Unconditional branch relative (always branches, saves bytes over `JMP`).
* **`STZ zp / abs / zpx / absx`**: Store Zero directly into memory without modifying `A`.
* **`PHX` / `PLX`**: Push / Pull Index register X to/from stack (`$0100-$01FF`).
* **`PHY` / `PLY`**: Push / Pull Index register Y to/from stack.
* **`TRB abs / zp`**: Test and Reset memory Bits using mask in accumulator.
* **`TSB abs / zp`**: Test and Set memory Bits using mask in accumulator.
* **`INC A` / `DEC A`**: Increment / Decrement Accumulator directly.
* **`WAI`**: Wait for Interrupt (pauses CPU until external IRQ/NMI).
* **`STP`**: Stop processor clock (halts CPU until hardware RESET).

### Rockwell Bit-Manipulation Instructions

* **`RMB0-7 zp`**: Reset memory bit (0 to 7) at zero page address.
* **`SMB0-7 zp`**: Set memory bit (0 to 7) at zero page address.
* **`BBR0-7 zp, rel`**: Branch if bit (0 to 7) at zero page address is reset (0).
* **`BBS0-7 zp, rel`**: Branch if bit (0 to 7) at zero page address is set (1).

### NMOS Bug Fixes in 65C02
* **`JMP ($xxFF)`**: Fixed indirect jump page-crossing wraparound bug (now fetches low byte from `$xxFF` and high byte from `$xx00+1`).
* **Decimal ADC / SBC**: Flag `N`, `V`, `Z` calculation accurately reflects decimal BCD result.
* **Dummy Reads**: Illegal and undefined NMOS opcodes execute as `NOP` with predictable multi-byte lengths rather than locking the bus.

## 4. Disassembler Interface

The CPU core provides an integrated disassembler [`CPU65C02.disassemble(pc)`](file:///h:/My%20Drive/Repos/Apple-II-Emulator/src/emulator/cpu/CPU65C02.ts) returning structured metadata:

```typescript
export interface DisassemblyLine {
  address: number;       // Instruction address ($0000-$FFFF)
  bytes: number[];       // 1 to 3 opcode/operand raw bytes
  opcode: string;        // Mnemonic (e.g., "LDA", "STZ", "JSR")
  operands: string;      // Formatted operand string (e.g., "#$05", "($20),Y")
  cycles: number;        // Base cycle count
  label?: string;        // Symbol name if matching known memory/softswitch
  isBreakpoint?: boolean;// True if address is registered in active breakpoint set
}
```
