Slinky 1MB-16MB Expanded RAM Protocol

The Apple //c Ultra implements the Apple Memory Expansion Card ("Slinky") protocol. It exposes a 24-bit auto-incrementing address counter that enables rapid block transfers of up to 16 megabytes: 

; Set 24-Bit Slinky Address to $040000 (256 KB Offset)
LDA #$00 : STA $C073 ; Address Low
LDA #$00 : STA $C074 ; Address Mid
LDA #$04 : STA $C075 ; Address High

; Stream 256 bytes into Slinky RAM (Address increments automatically)
LDX #$00
LOOP: LDA BUFFER,X
      STA $C071      ; Writes byte and increments 24-bit pointer
      INX
      BNE LOOP
