Slinky 1MB-16MB Expanded RAM Protocol

The Apple //c Ultra implements the Apple Memory Expansion Card ("Slinky") protocol. It exposes a 24-bit auto-incrementing address counter that enables rapid block transfers of up to 16 megabytes: 

; Set 24-Bit Slinky Address to $040000 (256 KB Offset)
LDA #$00 : STA $C073 ; Address Low
LDA #$00 : STA $C074 ; Address Mid
LDA #$04 : STA $C075 ; Address High

; Stream 256 bytes into Slinky RAM (Address increments automatically)
LDX #$00
LOOP: LDA BUFFER,X
      STA $C071      ; Writes byte and increments 24-bit pointer
      INX
      BNE LOOP

🎛️ Motherboard Peripheral Expansion Architecture (Slots 1–7)

The Apple //c Ultra implements an extensible peripheral slot architecture mapping Slots 1–7 to standard 256-byte firmware driver spaces ($C100–$C7FF) and 16-byte softswitch decoders ($C090–$C0FF).

Slot 1 ($C100) Epson FX-80 Parallel Printer Interface
Slot 2 ($C200) Super Serial Card (ACIA 6551)
Slot 3 ($C300) 80-Column Aux 64K Extended Video
Slot 4 ($C400) Mockingboard Dual AY-3-8910 Sound
Slot 5 ($C500) Sound Blaster / OPL2 FM Synthesis
Slot 6 ($C600) Disk II Dual 5.25" Floppy Controller (IWM)
Slot 7 ($C700) SmartPort 32MB Hard Disk Block Controller
