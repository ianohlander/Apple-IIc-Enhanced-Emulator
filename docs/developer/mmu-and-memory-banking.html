Memory Management Unit (MMU), Banking & 16MB Slinky RAM

1. Full 64KB Address Space Architecture

The Apple //c uses a unified 16-bit address bus spanning $0000 through $FFFF. The custom Apple MMU gate array partitions this address space into distinct functional regions, dynamically bank-switching between 128KB of onboard RAM (Main & Auxiliary), 32KB of Motherboard ROM, and 16MB of Slinky expanded RAM.

Apple //c Ultra 64KB Memory Map Breakdown

Address Range Size Primary Function Banking Mechanism & Controls
$0000 - $00FF 256 B Zero Page (High-speed 1-byte pointer & variable space) Banked via ALTZP ($C008=Aux, $C009=Main)
$0100 - $01FF 256 B Hardware 65C02 Stack Page Banked via ALTZP along with Zero Page
$0200 - $03FF 512 B Input buffer ($0200), Vectors, ProDOS global page ($0300) Banked via RAMRD / RAMWRT ($C002-$C005)
$0400 - $07FF 1 KB Text Screen Page 1 / Lo-Res Graphics Page 1 Banked via 80STORE ($C001) and PAGE2 ($C054/$C055)
$0800 - $0BFF 1 KB Text Screen Page 2 / Lo-Res Graphics Page 2 Switched via PAGE2 softswitch
$0C00 - $1FFF 5 KB Applesoft BASIC program memory / User RAM space Banked via RAMRD / RAMWRT
$2000 - $3FFF 8 KB Hi-Res Graphics Page 1 / Double Hi-Res (Main + Aux) Banked via 80STORE + HIRES + PAGE2 or RAMRD/RAMWRT
$4000 - $BFFF 32 KB Main Program Code, Modern Runtimes, Java/C# AOT Binary Banked via RAMRD / RAMWRT
$C000 - $CFFF 4 KB Hardware I/O Softswitches, Mockingboard, Slinky, Disk II Internal peripheral address decoding ($C000-$C0FF)
$D000 - $FFFF 12 KB Language Card Banked RAM (16KB) or Motherboard ROM Banked via $C080-$C08F (Bank 1 / Bank 2)

2. Auxiliary RAM, 80STORE & Video Page Banking Truth Table

The Apple //c features 128KB of total dynamic RAM divided into 64KB Main RAM and 64KB Auxiliary RAM. The 80STORE softswitch overrides general RAMRD/RAMWRT controls specifically for video memory buffers ($0400-$07FF and $2000-$3FFF):

80STORE ($C000/$C001) PAGE2 ($C054/$C055) HIRES ($C056/$C057) Memory Range Active Physical Target
0 (Off) 0 (Page 1) X (Don't care) $0400 - $07FF Main RAM Text Page 1
0 (Off) 1 (Page 2) X (Don't care) $0800 - $0BFF Main RAM Text Page 2
1 (On) 0 (Main Aux) 0 (Text) $0400 - $07FF Main RAM Text Page 1
1 (On) 1 (Aux Video) 0 (Text) $0400 - $07FF Auxiliary RAM Text Page 1 (80-Column Even Bytes)
1 (On) 0 (Main Aux) 1 (Hi-Res) $2000 - $3FFF Main RAM Hi-Res Page 1
1 (On) 1 (Aux Video) 1 (Hi-Res) $2000 - $3FFF Auxiliary RAM Hi-Res Page 1 (DHGR Aux Bytes)

3. Language Card 16KB Flip-Flop State Machine

The Language Card bank-switches the upper 12KB of address space ($D000..$FFFF) between Motherboard ROM and high-speed RAM. Softswitches in the range $C080 through $C08F control four parameters:

  • Bank Selection: Bit 3 ($08) determines whether Bank 1 ($D000-$DFFF, 4KB) or Bank 2 ($D000-$DFFF, 4KB alternate) is active. ($E000-$FFFF 8KB is shared).
  • Read Source: Bits 0 and 1 determine whether CPU reads come from RAM ($D000-$FFFF) or ROM.
  • Write Protection State Machine: Enabling RAM writes requires two consecutive read cycles to an odd address ($C081, $C083, $C089, $C08B). Any write cycle resets the pre-write flip-flop.

4. Slinky 16MB Expanded RAM Engine & Streaming DMA

The Apple //c Ultra implements the Apple II Memory Expansion Card (Slinky) extended to 16 Megabytes. It uses four hardware registers mapped at $C071-$C075:

Register Address Type Behavior & Auto-Increment
SLINKSW_ADDR_LOW $C071 R/W Bits 0-7 of 24-bit pointer address (Low Byte)
SLINKSW_ADDR_MID $C072 R/W Bits 8-15 of 24-bit pointer address (Middle Byte)
SLINKSW_ADDR_HIGH $C075 R/W Bits 16-23 of 24-bit pointer address (High Byte, up to 16MB)
SLINKSW_DATA $C073 R/W Auto-Incrementing Data Window: Reading or writing automatically increments the 24-bit pointer by 1 byte. 
; --- High-Speed 65C02 Slinky RAM Block Transfer ---
; Reads 256 bytes from 16MB Slinky into $4000 RAM buffer
        LDA #$00
        STA $C071       ; Set 24-bit address low = $00
        STA $C072       ; Set address mid = $00
        LDA #$01
        STA $C075       ; Set address high = $01 (Address = $010000 = 64KB mark)

        LDX #$00
READLP: LDA $C073       ; Read byte from Slinky (Auto-increments 24-bit pointer!)
        STA $4000,X     ; Store into local RAM buffer
        INX
        BNE READLP      ; Loop 256 times
        RTS
