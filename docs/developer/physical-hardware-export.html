Bare-Metal Deployment Floppy Emu & CFFA3000 Ready

Running Your C#, Java & BASIC Games on Real 1984 Apple II Hardware

One of the most thrilling capabilities of Apple //c Ultra is that every game or program you compile in modern C#, Java, or transcribe in the Type-In Studio can be exported with 1-click into a 100% authentic, bootable ProDOS disk image (.DSK / .PO / .2MG). You can drag and drop the exported file onto an SD card or USB drive, plug it into a physical Floppy Emu or CFFA3000, and power up an original Apple //c, Apple IIe, or Apple IIGS!

Supported Physical Apple II Hardware Devices

1. BMOW Floppy Emu SD Card

Plugs directly into the external disk DB-19 port of the Apple //c, or Disk II controller (Slot 6) on the Apple IIe.

Supported Formats: .DSK, .PO, .2MG
Modes: 5.25" Floppy, 3.5" HD, SmartPort
2. CFFA3000 Card USB / CF

Plugs into Slot 7 of Apple IIe / IIGS. Mounts 32MB hard disk volumes instantly with full ProDOS MLI support.

Supported Formats: .HDV, .PO, .2MG
Capacity: Up to 32MB Volume (/HD)
3. wDrive / FujiNet / ADTPro WiFi / Serial

wDrive OLED floppy emulator, FujiNet wireless network drive, or ADTPro serial cable transfers.

Supported Formats: .DSK, .PO, .NIB
Transfer: Direct Audio / RS-232 / SD

3-Step Deployment Workflow: From Web Studio to Real Silicon

How to take your code from browser to a physical Apple II in under 60 seconds

1 Step 1: Write or Compile Your Application

In the Modern Code Studio, select C# or Java (e.g. Retro Breakout or 3D Starfield Engine) and click "Compile to 65C02". The engine outputs native machine code starting at $2000.

2 Step 2: Click "Export .DSK for Floppy Emu"

Click the 💾 Export .DSK for Floppy Emu button in the toolbar. The built-in ProdosDiskExporter generates a valid 140KB floppy image containing:

  • Blocks 0 & 1: Standard 6502 ProDOS bootstrap code.
  • Block 2: Volume directory header (/MYAPP).
  • Block 6: ProDOS volume allocation bitmap.
  • File: AUTORUN.SYS (Type $FF System file containing your compiled 65C02 binary).
3 Step 3: Copy to SD Card & Power On Physical Apple II

Copy the downloaded MyApp_Bootable.dsk file to the root of your Floppy Emu SD card or CFFA3000 USB stick. Insert into your hardware emulator, select the disk image on the LCD screen, and turn on your Apple II. Your C# game will boot instantly on authentic 1984 silicon!

Disk Image Geometry & Container Specifications

140KB Standard Floppy (.DSK / .PO)
  • Total Capacity: 143,360 Bytes
  • Tracks: 35 Tracks (0 to 34)
  • Sectors: 16 Sectors / Track (256 Bytes/sec)
  • ProDOS Blocks: 280 Blocks (512 Bytes/blk)
  • Interleave Skew: ProDOS [0, 8, 1, 9, 2, 10, 3, 11...]
Universal 2MG Container (.2MG)
  • Header Size: 64 Bytes (Magic: 2IMG)
  • Creator ID: EMUL ($45 $4D $55 $4C)
  • Format Byte: $01 (ProDOS Order)
  • Data Offset: $00000040 (64 Bytes)
  • Compatible With: Floppy Emu, CFFA3000, Virtual ][, KEGS
