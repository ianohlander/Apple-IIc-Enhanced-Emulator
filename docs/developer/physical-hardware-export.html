Bare-Metal 65C02 Hardware Deployment Floppy Emu, CFFA3000, wDrive & FujiNet Ready

Running Any Virtual Workstation Application on Real 1984 Silicon

One of the most powerful features of the 65C02 Ultra Workstation is the ability to export ANY software created or tested inside the emulator—whether an Applesoft BASIC game, a handwritten 65C02 Assembly routine, a System ROM firmware image, or a modern C# .NET / Java 17 AOT-compiled application—directly into authentic, bootable disk images (.DSK, .PO, .2MG, or .HDV). You can transfer these files onto SD cards, USB flash drives, or WiFi bridges and boot them instantly on real physical vintage microcomputers!

2. Universal Software Scope: What Can You Export?

All Languages & Environments

The exporter is not restricted to any single language. Any software artifact created, loaded, or executed in the 65C02 Ultra Workstation can be packaged into a deployment disk:

📜 Applesoft BASIC Programs (.BAS / Type $FC)

Vintage listings typed into the Magazine Transcriber (such as Bird Brain, DHGR Kaleidoscope, or Lunar Lander) are tokenized into authentic binary Applesoft tokens ($0801 program memory) and packaged with a ProDOS BASIC.SYSTEM loader.

⚙️ 65C02 Assembly & Machine Code Binaries (.BIN / Type $06)

Machine code routines assembled at $0300, $0800, $2000, or $6000 in the Assembler Workbench are exported with authentic ProDOS/DOS 3.3 binary headers (Load Address + Length) ready for BLOAD execution.

☕ Modern C# .NET & Java 17 AOT Code (.SYS / Type $FF)

High-level C# or Java classes compiled by the Workstation's Ahead-Of-Time (AOT) engine are emitted as native 65C02 system binaries (AUTORUN.SYS) that boot directly at cold startup without needing any runtime interpreter.

🏛️ Custom System ROMs & Diagnostics (.ROM / 32KB)

Custom firmware ROMs modified in the ROM Workshop can be exported as raw 32KB binary images ($C000–$FFFF) to burn directly onto 27C256 physical EPROMs or load into RAM card expansions.

4. Universal 3-Step Deployment Workflow

Agnostic procedure for transferring any program from browser to physical silicon

1 Step 1: Create, Transcribe or Compile Your Application

Author your software in any supported environment inside the workstation:

  • Applesoft BASIC: Enter your program at the prompt or load it via the Magazine Transcriber.
  • 65C02 Assembly: Assemble source code into RAM in the Machine Language Workbench.
  • C# .NET / Java 17: Click "Compile & Run" in the CLR AOT Studio to generate machine code.
  • System ROM: Flash custom patches in the ROM Firmware Studio.
2 Step 2: Generate Disk Image via the 1-Click Exporter

Open the Floppy & 32MB Storage Bay or click the 💾 Export Disk Image button. The ProdosDiskExporter constructs a standardized disk image containing:

  • Blocks 0 & 1: Standard 6502 ProDOS / DOS 3.3 bootstrap sector code.
  • Block 2: ProDOS Volume Directory Header (e.g. /WORKSTATION).
  • Block 6: Volume Bitmap tracking allocated 512-byte blocks.
  • Target Binary / Script: AUTORUN.SYS, STARTUP.BAS, or raw BLOAD binary image.
3 Step 3: Transfer to Media & Boot Physical Hardware

Copy the downloaded .dsk, .po, or .2mg file to your flash adapter or stream it across the network:

  • BMOW Floppy Emu: Copy file to SD card root → Select file on LCD → Power on machine.
  • CFFA3000 Card: Copy file to USB stick → Mount in CFFA3000 configuration menu → Boot Slot 7.
  • FujiNet WiFi: Upload via FujiNet web interface → Mount to virtual D1 → Cold boot.
  • ADTPro: Send image over serial cable to write directly onto a physical magnetic 5.25" floppy!

5. Disk Image Geometry & Container Specifications

140KB Standard Floppy (.DSK / .PO)
  • Total Capacity: 143,360 Bytes
  • Tracks: 35 Tracks (0 to 34)
  • Sectors: 16 Sectors / Track (256 Bytes/sec)
  • ProDOS Blocks: 280 Blocks (512 Bytes/blk)
  • Interleave Skew: ProDOS [0, 8, 1, 9, 2, 10, 3, 11...]
Universal 2MG Container (.2MG)
  • Header Size: 64 Bytes (Magic: 2IMG)
  • Creator ID: EMUL ($45 $4D $55 $4C)
  • Format Byte: $01 (ProDOS Order)
  • Data Offset: $00000040 (64 Bytes)
  • Compatible With: Floppy Emu, CFFA3000, Virtual ][, KEGS
