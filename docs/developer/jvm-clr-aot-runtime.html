1. The Lineage: Sweet16, UCSD Pascal & Modern AOT

In 1977, Steve Wozniak created Sweet16, a 16-bit virtual machine interpreter embedded in Apple II Integer BASIC ROM ($F689..$F7FC). It simulated sixteen 16-bit virtual registers (R0-R15) in Zero Page. In 1979, the UCSD Pascal p-System introduced stack-based p-code bytecode execution to the 6502. The Apple //c Ultra advances this historical lineage by compiling high-level Java and C# .NET object-oriented source code directly into native, optimized 65C02 CMOS machine code ahead of time.

2. Zero Page Virtual Register Allocation ($80–$EF)

Because the 65C02 only has three 8-bit registers (A, X, Y), the AOT compiler maps 16-bit and 32-bit modern types to a dedicated pool of Zero Page virtual registers in Auxiliary RAM:

Virtual Register Address (ZP) Width Usage & Calling Convention
R0 (vAcc) $80, $81 16-bit Primary arithmetic accumulator and method return value
R1 (vArg1) $82, $83 16-bit First method argument / left operand in binary operations
R2 (vArg2) $84, $85 16-bit Second method argument / right operand
R3 (vThis) $86, $87 16-bit Pointer to active object instance ('this' pointer in Java / C#)
R4-R7 (vTemp) $88 - $8F 16-bit each Compiler scratch registers for complex sub-expression evaluation

3. Concrete Example: C# Method Lowering Walkthrough

Consider this C# method calculating Euclidean distance: 

// C# Source Code
public static int DistanceSq(int x0, int y0, int x1, int y1) {
    int dx = x1 - x0;
    int dy = y1 - y0;
    return (dx * dx) + (dy * dy);
}

The AOT compiler lowers this into the following native 65C02 CMOS assembly: 

; --- Lowered 65C02 Assembly ---
DISTSQ: ; dx = x1 - x0 (R1 = R2 - R1)
        SEC
        LDA $84         ; Low byte x1
        SBC $82         ; Subtract Low byte x0
        STA $88         ; Store in vTemp dx (Low)
        LDA $85         ; High byte x1
        SBC $83         ; Subtract High byte x0
        STA $89         ; Store in vTemp dx (High)

        ; dy = y1 - y0 (R2 = R4 - R3)
        SEC
        LDA $88         ; Low byte y1
        SBC $86         ; Subtract Low byte y0
        STA $8A         ; Store in vTemp dy (Low)
        ...
        ; (dx*dx) + (dy*dy) computed via 16-bit shift-and-add hardware subroutine
        JSR MULT16      ; Multiplies dx * dx -> R0
        RTS

4. Standard Class Libraries & Zero-Dependency Execution

The AOT compiler allows compiling pure Java and C# without importing any Apple-specific packages:

How Standard APIs Execute on 65C02 Silicon

  • System.Console.WriteLine & System.out.println: Character strings are converted to Apple II high-bit ASCII (ch | 0x80) and iterated through the Apple Monitor ROM Character Output vector (JSR $FDED [COUT]), followed by a carriage return (JSR $FD8E [CROUT]).
  • System.Collections.Generic.List<T> & java.util.ArrayList: Dynamically allocate contiguous object pointers in Auxiliary RAM ($4000-$BFFF).
  • System.Math & java.lang.Math: Min, Max, and Abs are lowered into 16-bit Zero Page register comparisons (CMP, BEQ, BMI, BPL) without requiring any external CRT or runtime libraries.
  • Optional Hardware Packages: Apple2.Ultra and apple2.hardware are purely optional interfaces for developers who specifically want direct access to retro hardware switches ($C050/$C057/$C05F Double Hi-Res, $C064 paddles, and Mockingboard PSG voices).
