1. Wozniak Scanline Interleaving & Mathematical Derivation

Steve Wozniak designed the Apple II video generator to eliminate expensive multiplier circuits and FIFO line buffers. Instead of linear frame buffers, the video counter hardware generates scanline addresses by dividing the 192 scanlines into three 64-line tiers ("boxes"), eight 8-line character rows per box, and eight scanline sublines per row.

Mathematical Formulation of Scanline Base Address

For any scanline Y from 0 to 191:

• Box: \(\text{Box} = \lfloor Y / 64 \rfloor \in \{0, 1, 2\}\)
• Row: \(\text{Row} = \lfloor (Y \bmod 64) / 8 \rfloor \in \{0..7\}\)
• Subline: \(\text{Sub} = Y \bmod 8 \in \{0..7\}\)
\(\text{Base Address}(Y) = $2000 + (\text{Sub} \times $0400) + (\text{Row} \times $0080) + (\text{Box} \times $0028)\)
Sample Calculated Addresses for Key Scanlines:
• Scanline 0: Box=0, Row=0, Sub=0 → $2000
• Scanline 1: Box=0, Row=0, Sub=1 → $2400
• Scanline 8: Box=0, Row=1, Sub=0 → $2080
• Scanline 64: Box=1, Row=0, Sub=0 → $2028
• Scanline 191: Box=2, Row=7, Sub=7 → $3FD0

2. Double Hi-Res (DHGR 560×192 16-Color) Bitstream Pipeline

Double Hi-Res graphics doubles the horizontal resolution by multiplexing 7 visual pixels from Auxiliary RAM and 7 visual pixels from Main RAM for every pair of display column bytes. The 14.31818 MHz master oscillator clocks out 560 monochrome dots per scanline.

4-Dot NTSC Phase Shift Color Synthesis

Because the NTSC color subcarrier frequency is \(f_{\text{color}} = 3.579545\text{ MHz} = \frac{14.31818\text{ MHz}}{4}\), exactly 4 monochrome dots span one 360° color subcarrier cycle. The 4-bit repeating binary pattern of dots generates a specific phase angle and amplitude, synthesizing 16 solid composite colors:

0: 0000 = Black
1: 0001 = Deep Red
2: 0010 = Dark Blue
3: 0011 = Purple
4: 0100 = Dark Green
5: 0101 = Dark Gray
6: 0110 = Medium Blue
7: 0111 = Light Blue
8: 1000 = Brown
9: 1001 = Orange
10: 1010 = Light Gray
11: 1011 = Pink
12: 1100 = Light Green
13: 1101 = Yellow
14: 1110 = Aquamarine
15: 1111 = White

3. CRT Phosphor Physics & Shader Emulation

The CRT display engine models electron beam scanning and phosphor decay across 4 monitor profiles:

  • Color NTSC: Full 16-color composite decoding with 4-dot artifacting.
  • P1 Green Phosphor (525nm): Classic Apple Monitor /// phosphor with long exponential persistence curve (\(I(t) = I_0 e^{-t/\tau}\) where decay time constant \(\tau \approx 28\text{ ms}\)).
  • P3 Amber Phosphor (605nm): High-contrast amber display with medium persistence (\(\tau \approx 12\text{ ms}\)).
  • P4 White Phosphor (Apple Monitor //c): Crisp monochrome phosphor matched to the original 9-inch Apple //c CRT display.
VRAM BUFFER

Physical 8KB Video RAM Bit-Level Framebuffering ($2000–$3FFF)

All Hi-Res graphics rendering in the Apple //c Ultra operates on physical byte arrays in VRAM. Every byte represents 7 horizontal screen dots (Bits 0–6) plus Bit 7 ($180^\circ$ NTSC color subcarrier delay):

Byte Address: Base(Y) + floor(X / 7)
Bit Mask: 1 << (X % 7)
HCOLOR 0 / 4 (Black): Clears dot bit (turns electron beam OFF in all phosphors).
HCOLOR 1 / 5 (Green / Orange): Sets dot bit (Bit 7 = 0 for Green, Bit 7 = 1 for Orange).
