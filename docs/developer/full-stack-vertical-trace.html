Layer 1: High-Level C# Source Application

Here is a complete C# program that reads the analog paddle controller, draws a Double Hi-Res bounding box, prints a message, and generates a dynamic sound tone based on paddle position: 

// RetroPaddleController.cs — High-Level C# Application
using System;
using Apple2.Ultra;

namespace ArcadeExperience
{
    public class PaddleApp
    {
        public static void Main()
        {
            // 1. Initialize Double Hi-Res 560x192 Graphics Mode
            AppleVideo.SetDoubleHiRes(true);
            AppleVideo.Clear(AppleVideo.Black);

            // 2. Standard Console Character Stream Output
            Console.WriteLine("PADDLE TRACKER ULTRA (65C02)");

            // 3. Read Analog Paddle 0 ($C064) & Synthesize Sound
            int paddlePos = AppleSystem.GetMouseX(); // 0..255
            int frequency = 440 + (paddlePos * 4);   // 440 Hz .. 1460 Hz
            AppleSound.Beep(frequency, 60);

            // 4. Render Paddle Line at bottom of CRT Screen
            AppleVideo.DrawLine(paddlePos * 2, 180, (paddlePos * 2) + 40, 180, AppleVideo.White);
        }
    }
}

Layer 2: AOT Compiler AST Lowering & Register Allocation

The Ahead-of-Time compiler traverses the Abstract Syntax Tree (AST) and maps the high-level C# expressions to Zero-Page virtual registers ($80-$8F) and hardware softswitch memory locations:

C# Expression / Variable Target Architecture Binding Lowering Transformation Strategy
AppleVideo.SetDoubleHiRes(true) $C050, $C057, $C00D, $C05F Emits hardware softswitch strobes: STA $C050 (Graphics), STA $C057 (Hi-Res), STA $C00D (80Col), STA $C05F (DHiRes).
Console.WriteLine("...") ROM Vector $FDED (COUT) Converts string characters to high-bit ASCII (ch | 0x80) and loops with LDA #$XX / JSR $FDED.
int paddlePos = GetMouseX() Virtual Register R1 ($82,$83) Reads hardware paddle register $C064, stores into Zero Page 16-bit register $82.
frequency = 440 + (paddlePos * 4) Virtual Register R0 ($80,$81) Shifts paddlePos left twice (ASL x2), then performs 16-bit addition with immediate constant 440 ($01B8).
AppleSound.Beep(frequency, 60) Speaker Flip-Flop $C030 Passes frequency to cycle-exact delay loop that toggles STA $C030.

Layer 3: Generated 65C02 Native Assembly & Hex Machine Code

The compiler outputs pure, relocatable 65C02 CMOS machine code loaded at target address $2000: 

; ==============================================================================
; GENERATED 65C02 CMOS ASSEMBLY LISTING FOR RETROPADDLECONTROLLER
; TARGET LOAD ADDRESS: $2000 | ENTRY POINT: $2000
; ==============================================================================
* = $2000

START:
  $2000: D8         CLD                     ; Clear decimal mode flag
  $2001: A2 FF      LDX #$FF                ; Initialize hardware stack pointer
  $2003: 9A         TXS                     ; SP = $FF

; --- Step 1: Set Double Hi-Res Graphics Mode ($C050, $C057, $C00D, $C05F) ---
  $2004: 8D 50 C0   STA $C050               ; Softswitch: TXTCLR (Graphics display on)
  $2007: 8D 57 C0   STA $C057               ; Softswitch: HIRES (Hi-Res graphics on)
  $200A: 8D 0D C0   STA $C00D               ; Softswitch: 80COLSET (80-column video on)
  $200D: 8D 5F C0   STA $C05F               ; Softswitch: DHIRESON (Double Hi-Res on)

; --- Step 2: Output Banner String via Apple Monitor ROM ($FDED: COUT) ---
  $2010: A9 D0      LDA #$D0                ; ASCII 'P' | 0x80
  $2012: 20 ED FD   JSR $FDED               ; Call Monitor ROM COUT routine
  $2015: A9 C1      LDA #$C1                ; ASCII 'A' | 0x80
  $2017: 20 ED FD   JSR $FDED
  $201A: A9 C4      LDA #$C4                ; ASCII 'D' | 0x80
  $201C: 20 ED FD   JSR $FDED
  $201F: A9 C4      LDA #$C4                ; ASCII 'D' | 0x80
  $2021: 20 ED FD   JSR $FDED
  $2024: A9 CC      LDA #$CC                ; ASCII 'L' | 0x80
  $2026: 20 ED FD   JSR $FDED
  $2029: A9 C5      LDA #$C5                ; ASCII 'E' | 0x80
  $202B: 20 ED FD   JSR $FDED
  $202E: 20 8E FD   JSR $FD8E               ; Call Monitor ROM CROUT (Carriage Return)

; --- Step 3: Read Paddle 0 ($C064) and Calculate Frequency ---
  $2031: AD 64 C0   LDA $C064               ; Read hardware Game Paddle 0 (0..255)
  $2034: 85 82      STA $82                 ; Store into Zero Page R1 (vArg1 Low)
  $2036: 64 83      STZ $83                 ; 65C02 Store Zero: R1 High = $00

  $2038: 0A         ASL A                   ; Multiply by 2 (paddlePos * 2)
  $2039: 0A         ASL A                   ; Multiply by 2 again (paddlePos * 4)
  $203A: 18         CLC                     ; Clear carry for 16-bit addition
  $203B: 69 B8      ADC #$B8                ; Add 440 ($01B8) Low Byte ($B8)
  $203D: 85 80      STA $80                 ; Store into Zero Page R0 (vAcc Low)
  $203F: A9 01      LDA #$01                ; High byte $01
  $2041: 69 00      ADC #$00                ; Add carry
  $2043: 85 81      STA $81                 ; Store into Zero Page R0 (vAcc High)

; --- Step 4: Generate Speaker Tone via $C030 Toggle Loop ---
TONE_LOOP:
  $2045: 8D 30 C0   STA $C030               ; Toggle 1-bit speaker diaphragm
  $2048: A2 40      LDX #$40                ; Delay constant based on frequency
DELAY:
  $204A: CA         DEX                     ; Decrement delay counter
  $204B: D0 FD      BNE DELAY               ; Loop until X == 0
  $204D: C6 80      DEC $80                 ; Decrement duration counter
  $204F: D0 F4      BNE TONE_LOOP           ; Continue tone pulse train

; --- Step 5: Clean Exit ---
  $2051: 60         RTS                     ; Return from subroutine to ProDOS / Caller

Layer 4: TypeScript Silicon Emulation Engine Execution

When the 65C02 executes opcode $8D $50 $C0 (STA $C050), the emulation engine intercepts the write at the MMU and updates the internal video generator state:

TypeScript CPU & MMU State Transition

// 1. CPU Opcode Dispatch in CPU65C02.step()
const opcode = this.readByte(this.pc++); // Reads 0x8D
const targetAddr = this.readWord(this.pc); // Reads 0xC050
this.pc += 2;
this.cycles += 4;

// 2. Memory Bus Write Routing in Apple2cMMU.writeByte()
if (targetAddr >= 0xC000 && targetAddr <= 0xC0FF) {
    this.handleSoftswitchWrite(targetAddr, this.a);
}

// 3. Video Mode Switch Update in Apple2cVideo.ts
case 0xC050: // TXTCLR
    this.textMode = false;
    this.dirty = true;
    break;
case 0xC057: // HIRES
    this.hiresMode = true;
    this.dirty = true;
    break;
case 0xC05F: // DHIRESON
    this.doubleHiresMode = true;
    this.dirty = true;
    break;

B. Audio Output (Web Audio API)

Speaker toggles at $C030 are buffered into an `AudioContext` pulse stream: 

const audioCtx = new AudioContext();
const osc = audioCtx.createOscillator();
const gain = audioCtx.createGain();
osc.type = 'square';
osc.frequency.setValueAtTime(frequency, audioCtx.currentTime);
gain.gain.exponentialRampToValueAtTime(0.01, audioCtx.currentTime + 0.06);
osc.connect(gain).connect(audioCtx.destination);
osc.start(); osc.stop(audioCtx.currentTime + 0.06);
