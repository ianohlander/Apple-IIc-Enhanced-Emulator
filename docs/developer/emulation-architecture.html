1. WDC 65C02 Core Architecture & Silicon Enhancements

The Apple //c Ultra is powered by an cycle-accurate emulation of the Western Design Center (WDC) 65C02 CMOS microprocessor. First released in 1983, the 65C02 represents a major evolution over the classic NMOS 6502 found in the original 1977 Apple II and II Plus. It is manufactured in high-density static CMOS silicon, drastically reducing power consumption while adding 27 new instructions, 8 new addressing modes, and fixing several notorious hardware bugs that plagued the NMOS version.

Detailed Silicon Comparison: NMOS 6502 vs. WDC 65C02

Architectural Feature Classic NMOS 6502 (1975) WDC 65C02 CMOS (1983 / Ultra)
Indirect JMP Page Boundary Bug Broken: JMP ($xxFF) fetches low byte from $xxFF and high byte incorrectly from $xx00 instead of crossing page boundary into $xx+1 00. Fixed: JMP ($xxFF) correctly increments high address byte across page boundary to fetch target address without corruption.
Decimal Mode Arithmetic Flags Undefined: When Decimal Flag ($D=1$), ADC and SBC leave the Zero ($Z$) and Negative ($N$) flags in an invalid, undefined state. Takes 1 extra cycle. Valid & Deterministic: Zero ($Z$) and Negative ($N$) flags reflect the actual BCD result. Decimal execution is 1 cycle faster.
Read-Modify-Write (RMW) Dummy Writes Spurious Writes: Instructions like INC $C030 or ROR $C000 write the unmodified value to memory before writing the modified value, triggering hardware softswitches twice! Clean Bus Cycles: Modifies internal registers before bus write; does not trigger double softswitch strobe.
Extended CMOS Instructions None (151 valid opcodes, 105 undefined/crash opcodes). 27 new opcodes: BRA, STZ, PHX/PLX, PHY/PLY, TRB/TSB, BBR/BBS, RMB/SMB, INC A, DEC A.
Clock Frequency Range 1.0227 MHz (Standard Apple II) 1.00 MHz to 50.00 MHz Turbo Mode with dynamic software throttling.

2. CPU Register Model & Status Flags (P)

The 65C02 possesses six fundamental hardware registers:

Primary Execution Registers

  • A (Accumulator, 8-bit): Central arithmetic and logical register. All mathematical computations (addition, subtraction, shifts, AND, OR, XOR) operate on A.
  • X (Index Register X, 8-bit): Used for array indexing, loop counting, and addressing modes such as ZeroPage,X and Absolute,X.
  • Y (Index Register Y, 8-bit): Used for secondary indexing, string traversal, and indirect-indexed addressing (Indirect),Y.
  • SP (Stack Pointer, 8-bit): Points into hardware stack page 1 ($0100-$01FF). Decrements on Push (PHA, PHP, PHX, PHY, JSR) and increments on Pull (PLA, PLP, PLX, PLY, RTS, RTI).
  • PC (Program Counter, 16-bit): Holds the address of the next instruction byte to fetch ($0000-$FFFF).

Processor Status Register P [7 6 5 4 3 2 1 0]

  • Bit 7 — N (Negative): Set to bit 7 of the calculation result (sign bit). 1 = Negative, 0 = Positive.
  • Bit 6 — V (Overflow): Set when a signed arithmetic operation overflows the range [-128..+127]. Also set directly by BIT instruction.
  • Bit 5 — Unused: Always reads as logic 1 when pushed to stack.
  • Bit 4 — B (Break Flag): Distinguishes hardware interrupts (IRQ/NMI, B=0) from software BRK instructions (B=1) during stack pushes.
  • Bit 3 — D (Decimal Mode): When set (SED), ADC and SBC perform BCD decimal arithmetic. Cleared via CLD.
  • Bit 2 — I (Interrupt Disable): When set (SEI), masks maskable hardware IRQ line interrupts. Cleared via CLI.
  • Bit 1 — Z (Zero): Set to 1 if arithmetic or logical result equals $00; cleared to 0 otherwise.
  • Bit 0 — C (Carry): Set if an addition overflows 8 bits (> 255) or if a subtraction does not require a borrow.

3. Binary & BCD Decimal Arithmetic Deep Dive

The 65C02 Arithmetic Logic Unit (ALU) performs two completely distinct modes of math depending on the state of the Decimal ($D$) flag. In Binary Mode ($D=0$), it executes standard two's-complement arithmetic. In Decimal Mode ($D=1$), it processes Binary Coded Decimal (BCD), where an 8-bit byte stores two decimal digits between 00 and 99.

Exact Mathematical Formulation of BCD Addition (ADC)

Given accumulator \(A\) and operand \(M\), with carry \(C_{in}\):

  1. Low Nibble Addition: \(AL = (A \pmod{16}) + (M \pmod{16}) + C_{in}\). If \(AL > 9\), adjust: \(AL = (AL + 6) \pmod{16}\), and propagate carry \(AH_{carry} = 1\).
  2. High Nibble Addition: \(AH = \lfloor A / 16 \rfloor + \lfloor M / 16 \rfloor + AH_{carry}\).
  3. High Nibble Overflow: If \(AH > 9\), adjust: \(AH = (AH + 6) \pmod{16}\), and set Carry Out \(C_{out} = 1\). Otherwise, \(C_{out} = 0\).
  4. Final Decimal Result: \(A_{new} = (AH \times 16) + AL\).
  5. Flags Update (65C02 Standard): \(Z = (A_{new} == 0)\), \(N = (A_{new} \ \& \ 0x80) \neq 0\).
Concrete Example: Adding $29 + $43 with Carry = 0.
• Low nibble: \(9 + 3 + 0 = 12\) ($0C). Since \(12 > 9\), \(AL = (12 + 6) \pmod{16} = 2\), \(AH_{carry} = 1\).
• High nibble: \(2 + 4 + 1 = 7\). Since \(7 \le 9\), \(AH = 7\), \(C_{out} = 0\).
• Final Result: \(A = $72\) (representing decimal 72). Valid: \(29 + 43 = 72\)!

4. Hardware Interrupt Processing & Vector Table

The 65C02 architecture utilizes a dedicated 6-byte hardware interrupt vector table hardwired at the top of memory address space ($FFFA-$FFFF):

Vector Address Interrupt Type Trigger Condition CPU Action & Stack Sequence
$FFFA / $FFFB NMI (Non-Maskable Interrupt) Negative-edge trigger on /NMI hardware pin (cannot be masked by I flag). Pushes PC high, PC low, and status register P (with B=0). Sets I=1. Jumps to address at ($FFFA). (Takes 7 cycles).
$FFFC / $FFFD RESET Low pulse on /RESET pin or pressing Control+Open-Apple+Reset. Sets I=1, D=0 (Decimal cleared on 65C02), sets SP=$FF, loads PC from ($FFFC). (Takes 7 cycles).
$FFFE / $FFFF IRQ / BRK Level-sensitive /IRQ line (Mockingboard VIA timer / mouse) or software BRK. If I=0: pushes PC+2, P (B=1 if BRK, B=0 if IRQ). Sets I=1. Jumps to address at ($FFFE). (Takes 7 cycles).
