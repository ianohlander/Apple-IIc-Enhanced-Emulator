2. WDC 65C02 CPU Emulation & Instruction Pipeline

The central processor is an accurate emulation of the Western Design Center (WDC) 65C02 CMOS microprocessor. In addition to executing the standard 151 opcodes of the original NMOS 6502, the 65C02 includes 27 new instructions, eliminates illegal opcodes, and provides bug-free decimal arithmetic flags.

Binary & BCD Decimal Arithmetic (ALU)

The 65C02 ALU supports both binary two's-complement arithmetic and Binary-Coded Decimal (BCD) arithmetic controlled by the Decimal flag (\(D \in P\)).

Binary Mode ADC / SBC Formula

Given Accumulator \(A\), Operand \(M\), and Carry In \(C_{in}\):

$$\text{Sum} = A + M + C_{in}$$
$$A_{new} = \text{Sum} \pmod{256}$$

Flags:

  • \(C = (\text{Sum} > 255)\)
  • \(Z = (A_{new} == 0)\)
  • \(N = (A_{new} \ \& \ 0x80) \neq 0\)
  • \(V = (\sim(A \oplus M) \ \& \ (A \oplus \text{Sum}) \ \& \ 0x80) \neq 0\)

Decimal Mode (BCD) ADC Algorithm

Each byte represents two 4-bit decimal digits (00..99):

  1. \(AL = (A \pmod{16}) + (M \pmod{16}) + C_{in}\)
  2. If \(AL > 9\): \(AL = (AL + 6) \pmod{16}\), \(AH_{carry} = 1\)
  3. \(AH = \lfloor A/16 \rfloor + \lfloor M/16 \rfloor + AH_{carry}\)
  4. If \(AH > 9\): \(AH = (AH + 6) \pmod{16}\), \(C_{out} = 1\)
  5. \(A_{new} = (AH \times 16) + AL\)
  6. 65C02 Fix: \(Z = (A_{new} == 0)\), \(N = (A_{new} \ \& \ 0x80) \neq 0\)

3. MMU Banking, Memory Mapping & 16MB Slinky RAM

The Apple //c MMU manages bank switching between 128KB of onboard dynamic RAM (64KB Main + 64KB Auxiliary), 32KB Motherboard ROM, and 16MB of Slinky expanded RAM through hardware I/O softswitches in the $C000-$C0FF range.

Language Card 16KB Banking State Machine

The Language Card region ($D000-$FFFF) maps 16KB of high-speed RAM over motherboard ROM. Softswitches in the range $C080..$C08F control Bank 1 ($D000-$DFFF 4KB), Bank 2 ($D000-$DFFF alternate 4KB), RAM Read vs ROM Read, and RAM Write-Enable protection. 

// Language Card 2-Cycle Read Write-Enable Protection Engine
public handleLanguageCardAccess(address: number, isWrite: boolean): void {
    const bank1 = (address & 0x08) === 0;
    const readRam = (address & 0x03) === 0x03 || (address & 0x03) === 0x00;
    const writeEnable = (address & 0x01) === 0x01;

    this.lcBank1 = bank1;
    this.lcReadRam = readRam;

    if (writeEnable) {
        // Must perform TWO consecutive READ cycles to an odd address ($C081, $C083, $C089, $C08B)
        if (this.preWriteFlipFlop && !isWrite) {
            this.lcWriteRam = true;
        }
        this.preWriteFlipFlop = !isWrite;
    } else {
        this.lcWriteRam = false;
        this.preWriteFlipFlop = false;
    }
}

4. Video Pipeline, Scanline Geometry & DHGR Graphics

Steve Wozniak designed the Apple II video generator to eliminate expensive multiplier circuits. The 192 scanlines are interleaved into three 64-line tiers ("boxes"), eight 8-line character rows per box, and eight scanlines per character row.

Double Hi-Res (DHGR 560×192 16-Color) Dot Serialization

Double Hi-Res graphics serializes 7 visual pixels from Auxiliary RAM and 7 visual pixels from Main RAM for every pair of display column bytes. Over the 40-byte row width, this outputs 80 bytes = 560 monochrome dots per scanline clocked at 14.31818 MHz. 4 consecutive monochrome dots form a 16-color composite pixel via NTSC color subcarrier phase shifting.

5. Audio Synthesis: 1-Bit Speaker & Dual AY-3-8910 Mockingboard

The Apple //c Ultra provides both the classic 1-bit speaker toggle at $C030 and a Slot 4 Mockingboard featuring dual General Instrument AY-3-8910 Programmable Sound Generator (PSG) chips driven by dual MOS 6522 VIAs.

AY-3-8910 Programmable Sound Generator (PSG) Register Map

  • R0 / R1: Channel A Tone Period (12-bit) — \(f = \frac{1022727}{16 \times \text{Period}}\)
  • R2 / R3: Channel B Tone Period (12-bit)
  • R4 / R5: Channel C Tone Period (12-bit)
  • R6: Noise Generator Period (5-bit) — 17-bit LFSR pseudo-random noise
  • R7: Audio Mixer Control (Tone / Noise enable mask, Active LOW)
  • R8, R9, R10: Channel A, B, C Volume (4-bit logarithmic amplitude + envelope enable bit)
  • R11 / R12: Envelope Period (16-bit) — \(T = \frac{256 \times \text{Period}}{1022727}\)
  • R13: Envelope Shape / Cycle (Sawtooth, Triangle, Attack/Decay)

6. Storage Architecture: Floppy GCR & SmartPort 32MB Hard Disk

The Apple //c Ultra supports both standard 5.25-inch 140KB floppy disks using Wozniak 6-and-2 Group Code Recording (GCR) and a 32MB SmartPort virtual hard disk volume ($/HD$) partitioned into 65,536 contiguous 512-byte blocks.

7. Java & .NET CLR Ahead-of-Time (AOT) Compilers

The Ahead-of-Time (AOT) compiler translates modern object-oriented Java and C# source code directly into native, optimized 65C02 CMOS machine code. It allocates 16-bit and 32-bit types into a dedicated pool of Zero Page virtual registers ($80-$8F) in Auxiliary RAM.

Zero Page Virtual Register Allocation Table ($80-$8F)

  • $80, $81: R0 (vAcc): Primary arithmetic accumulator and method return value (16-bit)
  • $82, $83: R1 (vArg1): First method argument / binary left operand (16-bit)
  • $84, $85: R2 (vArg2): Second method argument / binary right operand (16-bit)
  • $86, $87: R3 (vThis): Active object instance pointer ('this' in Java / C#) (16-bit)
  • $88 - $8F: R4-R7 (vTemp): Scratch registers for sub-expression evaluation (16-bit each)
