How to Use, Connect & Program Expansion Cards with External Hardware

The Apple //c Ultra virtualizes a full 50-pin, 7-slot motherboard expansion architecture. Each slot decodes 16 dedicated I/O softswitches ($C080 + $n0), a 256-byte Slot ROM ($Cn00), and optional banked 2KB expansion ROM ($C800–$CFFF).

This comprehensive guide explains where to find and operate every tool in the application UI, how the external end of an expansion card connects to real-world devices (such as physical Arduino / ESP32 sensors over USB Serial, live weather REST APIs, Web MIDI synthesizers, and WebSockets), and provides complete working code recipes in Applesoft BASIC, 65C02 Assembly, C# .NET, and Java 17.

The "External End" of an Expansion Card: Connecting to Real-World Hardware & APIs

How virtual peripheral cards bridge between host physical hardware and 65C02 silicon

In a physical 1984 Apple II computer, an expansion card has two distinct interfaces:

1. The Inside End (50-Pin Motherboard Bus):

Plugs into the motherboard. The 65C02 CPU reads and writes memory addresses in the card's 16-byte I/O window ($C080 + $n0) and executes firmware in the card's 256-byte Slot ROM ($Cn00).

2. The Outside End (External Ports & Devices):

Protrudes through the back slot of the case. Connects via ribbon cables, DB-9/DB-25 connectors, MIDI DIN plugs, or terminal blocks to real-world devices: weather instruments, serial printers, synthesizers, modems, or sensors.

How Does the Emulator Connect the "Outside End" of a Virtual Card?

Because the Apple //c Ultra runs in modern web environments, the "outside end" of your simulated card is implemented in JavaScript. Your card script can tap into modern web and hardware APIs to connect to any device in existence:

A. Physical USB Hardware & Microcontrollers (Web Serial API) navigator.serial

Plug real physical sensors into your PC/Mac via USB! If you connect an Arduino Uno, ESP32, Raspberry Pi Pico, or Teensy running real temperature, humidity, pressure, or anemometer sensors, your card script uses navigator.serial.requestPort() to stream raw sensor bytes directly into 65C02 registers in real-time.

B. Cloud IoT & Live REST Services (Fetch API) window.fetch()

Connect to internet telemetry services! Fetch live weather observations from OpenWeatherMap, NOAA, or Ambient Weather, smart home states from Home Assistant, live cryptocurrency prices from Coinbase, or live stock market feeds. The card stores the parsed telemetry in its registers for instant 65C02 access.

C. Physical Musical Synthesizers & Keyboards (Web MIDI API) navigator.requestMIDIAccess()

Connect real USB MIDI pianos, synth modules, and DAWs! When the 65C02 writes a byte to the Slot 2 MIDI card ($C0A1), it immediately transmits over USB to your Yamaha keyboard, Roland synthesizer, or Ableton Live software.

D. High-Speed Bidirectional Streaming (WebSockets & MQTT) new WebSocket()

Connect to local Python scripts, Node-RED flows, or industrial PLC devices! Stream hundreds of packets per second between your local machine and the virtual 65C02 bus.

Complete Case Study: IoT Multi-Sensor Weather Station Card

Step-by-step walkthrough: Register specification, JavaScript bridge, and software in 4 languages

1. Hardware Specification & Register Memory Map (Slot 3 @ $C0B0)

Our custom Ultra Environmental Weather Station Card is plugged into Slot 3. It exposes 8 hardware registers in the 65C02 I/O zone ($C0B0–$C0B7):

Address BASIC PEEK/POKE Type Register Name Description & Units
$C0B0 PEEK(49328) Read TEMP_DATA Current Temperature (Integer °F, e.g. 74)
$C0B1 PEEK(49329) Read HUMID_DATA Relative Humidity (0–100% RH)
$C0B2 PEEK(49330) Read PRESS_LOW Barometric Pressure Low Byte (hPa × 10 MOD 256)
$C0B3 PEEK(49331) Read PRESS_HIGH Barometric Pressure High Byte (hPa × 10 / 256)
$C0B4 PEEK(49332) Read WIND_SPEED Wind Speed (Miles Per Hour)
$C0B5 PEEK(49333) Read RAIN_GAUGE Accumulated Daily Rainfall (Hundredths of an inch)
$C0B6 POKE 49334, V Write CONTROL_CMD Command (0=Metric, 1=Imperial, $FF=Reset Rain Gauge)
$C0B7 PEEK(49335) Read STATUS_FLAG Status Strobe (Bit 7 = 1 when data valid & ready)

2. The Card JavaScript Code (Paste into the Slot 3 Sandbox)

Under the Hood → Slot & Card Studio → Custom JS Sandbox

Paste this script into the Custom JS Card Sandbox in the Slot & Card Studio and click ▶ Apply to Slot 3: 

// ============================================================================
// Ultra IoT Weather Station Card (Slot 3 @ $C0B0)
// Connects live environmental sensors to the 65C02 bus
// ============================================================================

card.tempF = 74;
card.humidity = 52;
card.pressure = 1013.2; // hPa
card.windSpeed = 12;    // mph
card.rainGauge = 8;     // 0.08 inches

// Simulate live continuous telemetry updates (or replace with fetch/serial)
setInterval(() => {
  card.tempF = 72 + Math.floor(Math.random() * 6);
  card.humidity = 48 + Math.floor(Math.random() * 10);
  card.windSpeed = 8 + Math.floor(Math.random() * 8);
}, 4000);

// 65C02 Softswitch Read Handler ($C0B0–$C0BF)
card.onReadHandler = (offset) => {
  if (offset === 0x00) return card.tempF & 0xFF;                  // $C0B0
  if (offset === 0x01) return card.humidity & 0xFF;               // $C0B1
  
  // 16-bit Barometric Pressure (hPa * 10)
  const pressInt = Math.floor(card.pressure * 10);
  if (offset === 0x02) return pressInt & 0xFF;                   // $C0B2 (Low)
  if (offset === 0x03) return (pressInt >> 8) & 0xFF;            // $C0B3 (High)
  
  if (offset === 0x04) return card.windSpeed & 0xFF;              // $C0B4
  if (offset === 0x05) return card.rainGauge & 0xFF;              // $C0B5
  if (offset === 0x07) return 0x80;                              // $C0B7: Ready
  return 0x00;
};

// 65C02 Softswitch Write Handler
card.onWriteHandler = (offset, val) => {
  if (offset === 0x06 && val === 0xFF) {
    card.rainGauge = 0; // Reset Rain Gauge
    console.log("Rain gauge reset by Apple II command!");
  }
};

B. Modern C# .NET High-Performance Weather App Under the Hood → ☕ Java & C# CLR

Instructions: Switch to the ☕ Java & C# CLR tab in the workbench, paste this C# class into the Code Entry textbox, and click ⚡ Compile & Run on Apple II: 

using System;
using Apple2.Ultra;

public class WeatherStationApp {
    public static void Main() {
        AppleConsole.ClearScreen();
        AppleConsole.WriteLine(" C# AOT WEATHER STATION (SLOT 3)");
        AppleConsole.WriteLine("--------------------------------");
        
        // Read Slot 3 ($C0B0) registers
        byte temp = AppleMemory.Peek(0xC0B0);
        byte humid = AppleMemory.Peek(0xC0B1);
        int pressLow = AppleMemory.Peek(0xC0B2);
        int pressHigh = AppleMemory.Peek(0xC0B3);
        int pressure = (pressLow + (pressHigh << 8)) / 10;
        byte wind = AppleMemory.Peek(0xC0B4);
        
        AppleConsole.WriteLine("TEMPERATURE : " + temp + " F");
        AppleConsole.WriteLine("HUMIDITY    : " + humid + " %");
        AppleConsole.WriteLine("PRESSURE    : " + pressure + " hPa");
        AppleConsole.WriteLine("WIND SPEED  : " + wind + " MPH");
        
        if (temp > 85) {
            AppleAudio.Beep(frequency: 800, durationMs: 150);
            AppleConsole.WriteLine("[!] HIGH TEMPERATURE ALERT");
        }
    }
}

D. Pure 65C02 Assembly Telemetry Sampler High-Speed Interrupt / $0300

Fast machine language routine to read all 6 sensor registers into Zero Page buffers ($80–$85) in 18 clock cycles: 

; --- READ WEATHER SENSORS AT $C0B0 TO ZERO PAGE $80-$85 ---
SAMPLE_SENSORS:
    LDX #$00        ; Initialize register offset index
READ_LOOP:
    LDA $C0B0,X     ; Read Slot 3 sensor register ($C0B0 + X)
    STA $80,X       ; Store into Zero Page telemetry buffer ($80 + X)
    INX
    CPX #$06        ; Sampled all 6 sensor channels?
    BNE READ_LOOP
    RTS             ; Return to caller (Total: 18 microseconds)

Connecting Physical Arduino / ESP32 Sensors over USB

How to connect real breadboard circuits, temperature probes, and dials into the Apple II

Hobbyists can connect physical microcontrollers (Arduino Uno, ESP32, Raspberry Pi Pico) directly to the Apple //c Ultra via the Web Serial API. Here is the complete blueprint:

1. Arduino C++ Firmware (Flash to Microcontroller): 
// Arduino Uno / ESP32 Sensor Sketch
void setup() {
  Serial.begin(9600); // 9600 Baud USB Serial
}

void loop() {
  int rawTemp = analogRead(A0); // Read analog temp sensor
  byte tempF = map(rawTemp, 0, 1023, 32, 120);
  
  Serial.write(tempF); // Send 1 byte to Apple II
  delay(1000);        // Send every 1 second
}
2. Sandbox JavaScript Web Serial Bridge (Slot 3): 
// Custom Web Serial Card in Sandbox
card.liveSensorByte = 70;

// Connect USB Serial Port
card.connectUsb = async () => {
  const port = await navigator.serial.requestPort();
  await port.open({ baudRate: 9600 });
  const reader = port.readable.getReader();
  while (true) {
    const { value, done } = await reader.read();
    if (done) break;
    if (value && value.length > 0) {
      card.liveSensorByte = value[0];
    }
  }
};

card.onReadHandler = (offset) => {
  if (offset === 0x00) return card.liveSensorByte;
  return 0;
};

MIDI_NOTE_ON:
