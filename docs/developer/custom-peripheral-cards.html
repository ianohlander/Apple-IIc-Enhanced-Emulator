The Complete Guide to Custom Peripheral Card Engineering

The Apple //c Ultra virtualizes a full 50-pin, 7-slot motherboard expansion architecture. Each slot decodes 16 dedicated I/O softswitches ($C080 + $n0), a 256-byte Slot ROM ($Cn00), and optional banked 2KB expansion ROM ($C800–$CFFF).

This document provides the complete JavaScript Emulator Sandbox API specification, details all properties, methods, and lifecycle callbacks of the card object, provides exhaustive data structures and object models for Web Serial (Arduino/ESP32), Fetch (REST IoT APIs), Web MIDI, and WebSockets, and explains where and how to write and run code in Applesoft BASIC, 65C02 Assembly, C# .NET, and Java 17.

🧪 Where is the Custom Card JavaScript Sandbox?
Slot & Card Studio

The Custom Card JavaScript Sandbox is a built-in feature of the Apple //c Ultra emulator. It allows you to write custom hardware logic for Slot 3 (I/O registers at $C0B0–$C0BF) directly in the browser with real-time compilation!

How to Open and Use the Sandbox:
  1. Launch the emulator: open index-standalone.html in any modern browser.
  2. Scroll down below the CRT screen to the "Under the Hood" workbench area.
  3. Click the 🎛️ Slot & Card Studio workbench tab (Tab 9).
  4. Inside the studio, click the 🧪 Custom JS Card Sandbox (Slot 3) button.
  5. Select a preset (e.g. 🌤️ IoT Weather Station, 🔌 Web Serial Arduino Bridge, 📈 Live Bitcoin Ticker, or 🧮 32-Bit Math Co-Processor) or write your custom code in the JavaScript Sandbox Textarea.
  6. Click the blue ▶ Apply to Slot 3 button. Your virtual hardware card is immediately active on the 65C02 bus!
☕ Where Do I Enter and Run C# and Java Code?
Java & C# AOT Studio

All modern C# and Java code samples provided in this guide are designed for the emulator's Ahead-Of-Time (AOT) Compiler Engine. You do NOT need a local .NET SDK or JDK installed.

How to Compile & Run C# / Java Code:
  1. In the "Under the Hood" workbench area, click the ☕ Java & C# CLR tab (Tab 7).
  2. Select your language (C# .NET or Java 17) from the language selector.
  3. Paste the C# or Java class into the large Source Code Textbox.
  4. Click the gold ⚡ Compile & Run on Apple II button.
  5. The AOT compiler translates the high-level code down to native 65C02 machine code, injects it into Apple II memory at $0800, and jumps to it (CALL 2048) automatically!

Full JavaScript Emulator Sandbox 'card' API Reference

Complete property definitions, method signatures, return types, and lifecycle event callbacks

When you write script code in the Custom JS Card Sandbox, your code executes with direct access to the card instance. Below is the complete TypeScript / JavaScript interface definition representing everything you can read, write, override, and hook: 

// Complete JavaScript Sandbox 'card' Object Interface Definition
interface ICustomScriptableCard {
  // --- METADATA & CONFIGURATION PROPERTIES ---
  name: string;             // Human-readable card name (e.g. "IoT Weather Station")
  slot: number;             // Slot index (default 3: maps to $C0B0 I/O & $C300 ROM)
  description: string;      // Card description displayed in Under the Hood diagnostics
  icon: string;             // Emoji / icon character (e.g. "🌤️", "🔌", "📈")
  isPlugged: boolean;       // Set true to connect to motherboard bus, false to float High-Z

  // --- MEMORY BUFFERS ---
  registers: number[];      // 16-element array (0x00 to 0x0F) for I/O softswitches ($C0B0–$C0BF)
  rom: number[];            // 256-element array (0x00 to 0xFF) for Slot ROM ($C300–$C3FF)
  expansionRom: number[];   // 2048-element array (0x000 to 0x7FF) for Banked ROM ($C800–$CFFF)
  state: Record<string, any>; // Custom dictionary for storing arbitrary user state/objects

  // --- PRIMARY LIFECYCLE EVENT CALLBACKS (OVERRIDABLE) ---
  
  /**
   * Called whenever 65C02 executes a read from the card's 16 I/O softswitches ($C0B0–$C0BF)
   * Triggered by: LDA $C0B0, PEEK(49328), C# AppleMemory.Peek(0xC0B0), Java AppleSystem.peek(0xC0B0)
   * @param offset Integer register index (0x00 to 0x0F, where 0x00 = $C0B0, 0x01 = $C0B1, ...)
   * @returns 8-bit unsigned integer (0 to 255) returned to the 65C02 accumulator / bus
   */
  onReadHandler?: (offset: number) => number;

  /**
   * Called whenever 65C02 executes a write to the card's 16 I/O softswitches ($C0B0–$C0BF)
   * Triggered by: STA $C0B0, POKE 49328, V, C# AppleMemory.Poke(0xC0B0, V), etc.
   * @param offset Integer register index (0x00 to 0x0F)
   * @param value 8-bit unsigned integer (0 to 255) written by the 65C02
   */
  onWriteHandler?: (offset: number, value: number) => void;

  /**
   * Optional: Called whenever 65C02 reads from the card's 256-byte Slot ROM ($C300–$C3FF)
   * @param offset Byte offset within ROM (0x00 to 0xFF)
   * @returns 8-bit opcode or data byte (0 to 255)
   */
  onRomReadHandler?: (offset: number) => number;

  /**
   * Optional: Called continuously during CPU execution cycles for timing, counters, or polling
   * @param cycles Number of 65C02 clock cycles executed since last tick (e.g. 1,020,484 cycles/sec)
   */
  onTickHandler?: (cycles: number) => void;

  /**
   * Optional: Called when the Apple II undergoes a hard power reset or soft Ctrl-Reset
   */
  onResetHandler?: () => void;

  // --- BUILT-IN HELPER UTILITY METHODS ---
  setRegister(offset: number, value: number): void; // Set register value (0-15)
  getRegister(offset: number): number;              // Get register value (0-15)
  loadRomBytes(bytes: number[] | Uint8Array, startOffset?: number): void; // Bulk load 65C02 code
  getDiagnostics(): Record<string, number | string | boolean>; // Return status dictionary
}

Detailed Method & Callback Signatures

card.onReadHandler = (offset) => number Softswitch Read Hook

When It Fires: Every time the 65C02 CPU reads an address between $C0B0 and $C0BF (for Slot 3).

  • offset (number): Value from 0 to 15 (0x00 = $C0B0, 0x01 = $C0B1, ... 0x0F = $C0BF).
  • Return Value (number): Must return an integer from 0 to 255 (the emulator automatically masks with & 0xFF).
// Example: Return temperature on offset 0, humidity on offset 1
card.onReadHandler = (offset) => {
  if (offset === 0x00) return 74;  // $C0B0: 74 deg F
  if (offset === 0x01) return 55;  // $C0B1: 55% humidity
  return 0x00;
};
card.onWriteHandler = (offset, value) => void Softswitch Write Hook

When It Fires: Every time the 65C02 CPU writes an address between $C0B0 and $C0BF (e.g. POKE 49328, 42).

  • offset (number): Register index (0x00 to 0x0F).
  • value (number): 8-bit integer (0 to 255) written by the CPU.
// Example: Listen for control commands written to $C0B6
card.onWriteHandler = (offset, value) => {
  if (offset === 0x06 && value === 0xFF) {
    console.log("Apple II sent reset command!");
    card.rainCounter = 0;
  }
};
card.onTickHandler = (cycles) => void CPU Cycle Timer Hook

When It Fires: Executed in synchronization with CPU execution (approximately 1,020,484 cycles/sec at 1 MHz, or up to 50,000,000 cycles/sec at 50 MHz Turbo). 

// Example: Decrement an internal hardware timer every 10,000 cycles
card.cycleCounter = 0;
card.onTickHandler = (cycles) => {
  card.cycleCounter += cycles;
  if (card.cycleCounter >= 1000000) { // ~1 second elapsed
    card.cycleCounter = 0;
    card.secondsOnline = (card.secondsOnline || 0) + 1;
  }
};

🔌 1. Web Serial API: Connecting Physical USB Microcontrollers (Arduino / ESP32)
navigator.serial

The Web Serial API allows web applications to read from and write to physical serial hardware devices (such as microcontrollers, GPS receivers, custom breadboards, and lab equipment) plugged into your computer's USB ports.

Web Serial Object Model & Data Types:
  • navigator.serial: The entry point object provided by modern browsers (Chrome 89+, Edge 89+, Opera).
  • port = await navigator.serial.requestPort(): Prompts user with a secure browser modal to pick a USB COM port. Returns a SerialPort object.
  • await port.open({ baudRate: 9600, dataBits: 8, stopBits: 1, parity: 'none' }): Configures hardware UART baud rate and framing.
  • port.readable.getReader(): Returns a stream reader yielding Uint8Array byte buffers.
  • port.writable.getWriter(): Returns a stream writer accepting Uint8Array to transmit bytes to the microcontroller.
A. Arduino C++ Firmware (Upload to Arduino Uno / Nano): 
// Arduino Uno / ESP32 Sensor Transmitter
void setup() {
  Serial.begin(9600); // 9600 Baud Serial
}

void loop() {
  int sensorRaw = analogRead(A0); // Read analog pin
  byte tempF = map(sensorRaw, 0, 1023, 32, 120);
  
  // Send 1 byte directly to Apple //c Ultra
  Serial.write(tempF);
  
  // Check if Apple II sent a command back
  if (Serial.available() > 0) {
    byte cmd = Serial.read();
    if (cmd == 0x01) digitalWrite(LED_BUILTIN, HIGH);
  }
  delay(500); // Sample twice per second
}
B. Sandbox JavaScript Web Serial Card (Slot 3): 
// Web Serial USB Hardware Bridge Card
card.liveSensorByte = 72;
card.serialPort = null;
card.serialWriter = null;

// Connect USB Serial Port Button Handler
card.connectUsb = async () => {
  try {
    if (!('serial' in navigator)) {
      alert("Web Serial is supported in Chrome/Edge on localhost or HTTPS.");
      return;
    }
    card.serialPort = await navigator.serial.requestPort();
    await card.serialPort.open({ baudRate: 9600 });
    
    // Setup background stream reader
    const reader = card.serialPort.readable.getReader();
    card.serialWriter = card.serialPort.writable.getWriter();
    
    while (true) {
      const { value, done } = await reader.read();
      if (done) break;
      if (value && value.length > 0) {
        card.liveSensorByte = value[0]; // Latched
      }
    }
  } catch (err) {
    console.warn("Serial Error:", err);
  }
};

// 65C02 Softswitch Handlers
card.onReadHandler = (offset) => {
  if (offset === 0x00) return card.liveSensorByte; // $C0B0
  return 0x00;
};

card.onWriteHandler = async (offset, val) => {
  // Transmit byte from Apple II to Arduino over USB!
  if (offset === 0x00 && card.serialWriter) {
    await card.serialWriter.write(new Uint8Array([val]));
  }
};
🌐 2. Fetch API: Cloud IoT, Live Weather & Financial REST Services
window.fetch()

Using standard fetch(), your virtual card can query any HTTP REST endpoint (such as OpenWeatherMap, CoinGecko, Home Assistant, or local LAN REST servers) and store the parsed JSON values into 65C02 registers. 

// Cloud REST Telemetry Card (Slot 3 @ $C0B0)
card.bitcoinPrice = 95000;
card.tempF = 72;

// Query REST API every 30 seconds
async function fetchCloudData() {
  try {
    const res = await fetch("https://api.coindesk.com/v1/bpi/currentprice.json");
    const json = await res.json();
    card.bitcoinPrice = Math.floor(json.bpi.USD.rate_float);
  } catch (e) {
    console.warn("REST fetch error:", e);
  }
}

fetchCloudData();
setInterval(fetchCloudData, 30000);

card.onReadHandler = (offset) => {
  // Return 24-bit integer across 3 registers ($C0B0, $C0B1, $C0B2)
  if (offset === 0x00) return card.bitcoinPrice & 0xFF;         // Low byte
  if (offset === 0x01) return (card.bitcoinPrice >> 8) & 0xFF;  // Mid byte
  if (offset === 0x02) return (card.bitcoinPrice >> 16) & 0xFF; // High byte
  return 0x00;
};
🎹 3. Web MIDI API: USB Synthesizers, Keyboards & DAWs
navigator.requestMIDIAccess()

Connects 65C02 sound routines directly to physical musical hardware via standard 3-byte MIDI packets ([status, noteNumber, velocity]). 

// Web MIDI Transceiver Card
card.midiOutput = null;

card.initMidi = async () => {
  if ('requestMIDIAccess' in navigator) {
    const access = await navigator.requestMIDIAccess();
    const outputs = Array.from(access.outputs.values());
    if (outputs.length > 0) {
      card.midiOutput = outputs[0]; // Attach to first USB synthesizer
      console.log("Connected to MIDI Output:", card.midiOutput.name);
    }
  }
};
card.initMidi();

// 65C02 writes: $C0B0 = Note Number (60 = Middle C), $C0B1 = Trigger Note On
card.currentNote = 60;
card.onWriteHandler = (offset, val) => {
  if (offset === 0x00) card.currentNote = val & 0x7F;
  if (offset === 0x01 && card.midiOutput) {
    // Transmit MIDI Note-On: Channel 1 (0x90), Pitch, Velocity (0x7F = 127)
    card.midiOutput.send([0x90, card.currentNote, 0x7F]);
    setTimeout(() => card.midiOutput.send([0x80, card.currentNote, 0x00]), 300); // Note-Off
  }
};

2. JavaScript Card Script (Paste in Slot 3 Sandbox)

// Ultra IoT Weather Station Card (Slot 3 @ $C0B0)
card.tempF = 74;
card.humidity = 52;
card.pressure = 1013.2; // hPa
card.windSpeed = 12;    // mph
card.rainGauge = 8;     // 0.08 in

setInterval(() => {
  card.tempF = 72 + Math.floor(Math.random() * 6);
  card.humidity = 48 + Math.floor(Math.random() * 10);
  card.windSpeed = 8 + Math.floor(Math.random() * 8);
}, 4000);

card.onReadHandler = (offset) => {
  if (offset === 0x00) return card.tempF & 0xFF;                  // $C0B0
  if (offset === 0x01) return card.humidity & 0xFF;               // $C0B1
  const pressInt = Math.floor(card.pressure * 10);
  if (offset === 0x02) return pressInt & 0xFF;                   // $C0B2 (Low)
  if (offset === 0x03) return (pressInt >> 8) & 0xFF;            // $C0B3 (High)
  if (offset === 0x04) return card.windSpeed & 0xFF;              // $C0B4
  if (offset === 0x05) return card.rainGauge & 0xFF;              // $C0B5
  if (offset === 0x07) return 0x80;                              // $C0B7: Ready Strobe
  return 0x00;
};

card.onWriteHandler = (offset, val) => {
  if (offset === 0x06 && val === 0xFF) {
    card.rainGauge = 0;
    console.log("Rain gauge reset by Apple II command!");
  }
};

public class WeatherStationApp {
