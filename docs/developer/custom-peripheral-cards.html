Virtual Bus & Slot Architecture Slots 1 through 7

How to Create and Simulate Custom Apple II Peripheral Cards

The Apple II bus architecture is legendary for its open, modular slot design. In the Apple //c Ultra emulator, all peripheral cards (Mockingboard, Slinky RAM, Uthernet, Disk II, and SmartPort HD) implement a clean, decoupled IPeripheralCard contract. This guide explains how the bus decodes slot addresses, how to write your own custom card simulation in TypeScript/JavaScript, and how to bridge virtual 65C02 registers to modern Web APIs (Web MIDI, WebSockets, RTC).

The Standard IPeripheralCard TypeScript Contract

Every peripheral card in the Apple //c Ultra architecture adheres to this minimal, decoupled interface: 

export interface IPeripheralCard {
  /** Display name of the peripheral card */
  readonly name: string;

  /** Expansion slot index (1 through 7) */
  readonly slot: number;

  /** Human-readable hardware description */
  readonly description: string;

  /**
   * Read from the card's 16-byte dedicated softswitch register space ($C080 + $n0)
   * @param offset Register index 0x00 to 0x0F
   * @returns 8-bit value (0x00 - 0xFF)
   */
  ioRead(offset: number): number;

  /**
   * Write to the card's 16-byte dedicated softswitch register space ($C080 + $n0)
   * @param offset Register index 0x00 to 0x0F
   * @param value 8-bit data written by CPU (0x00 - 0xFF)
   */
  ioWrite(offset: number, value: number): void;

  /**
   * Read from the card's 256-byte on-board firmware ROM ($C100 + $n00 to $C1FF + $n00)
   * @param offset ROM byte index 0x00 to 0xFF
   * @returns 8-bit opcode/data byte
   */
  romRead(offset: number): number;

  /**
   * Optional: Read from the 2KB shared expansion ROM ($C800-$CFFF)
   */
  expansionRomRead?(offset: number): number;

  /** Reset card hardware state to power-on defaults */
  reset(): void;

  /**
   * Optional cycle clock tick for timing counters, audio DACs, or periodic IRQ triggers
   * @param cycles Number of CPU clock cycles elapsed
   */
  tick?(cycles: number): void;
}

3 Production-Ready Card Blueprints

Blueprint 1: Thunderclock / No-Slot Clock RTC Card (Slot 4) ProDOS Time Driver

Provides the host computer's exact real-time clock and date to ProDOS without requiring physical Dallas DS1216 smartwatch chips: 

export class ThunderclockCard implements IPeripheralCard {
  public readonly name = "Thunderclock Plus RTC";
  public readonly slot = 4;
  public readonly description = "Real-Time Clock & ProDOS Date Driver";
  private latchRegister = 0;

  public ioRead(offset: number): number {
    const now = new Date();
    switch (offset) {
      case 0x00: return now.getSeconds();
      case 0x01: return now.getMinutes();
      case 0x02: return now.getHours();
      case 0x03: return now.getDate();
      case 0x04: return now.getMonth() + 1;
      case 0x05: return now.getFullYear() % 100;
      default: return 0x00;
    }
  }

  public ioWrite(offset: number, value: number): void {
    this.latchRegister = value;
  }

  public romRead(offset: number): number {
    // ProDOS Clock Card ID Signature at $C400: $08, $28, $58, $70
    const rom = [0x08, 0x28, 0x58, 0x70];
    return offset < rom.length ? rom[offset] : 0x60; // RTS ($60)
  }

  public reset(): void { this.latchRegister = 0; }
}
Blueprint 2: Passport / Yamaha Web MIDI Master Card (Slot 2) Web MIDI API Bridge

Connects vintage 65C02 MIDI sequencing software (Passport Master Tracks, Music Construction Set) directly to modern USB MIDI synthesizers via the browser's navigator.requestMIDIAccess(): 

export class WebMidiCard implements IPeripheralCard {
  public readonly name = "Passport MIDI Master Card";
  public readonly slot = 2;
  public readonly description = "6850 ACIA MIDI Controller connected to Web MIDI API";
  private midiOutput: any = null;

  constructor() {
    if (typeof navigator !== 'undefined' && (navigator as any).requestMIDIAccess) {
      (navigator as any).requestMIDIAccess().then((midi: any) => {
        const outputs = Array.from(midi.outputs.values());
        if (outputs.length > 0) this.midiOutput = outputs[0];
      });
    }
  }

  public ioRead(offset: number): number {
    // 6850 ACIA Status Register ($C0A0): Bit 1 = Transmit Buffer Empty (1)
    if (offset === 0x00) return 0x02; 
    return 0x00;
  }

  public ioWrite(offset: number, value: number): void {
    // 6850 ACIA Data Register ($C0A1): Send raw MIDI byte stream
    if (offset === 0x01 && this.midiOutput) {
      this.midiOutput.send([value]);
    }
  }

  public romRead(offset: number): number { return 0x60; }
  public reset(): void {}
}
Blueprint 3: Live Web IoT & Sensor Bridge Card (Slot 5) Fetch / REST API Bridge

Allows an Apple II BASIC or C# program to read live ambient temperature, cryptocurrency prices, or weather telemetry from the internet by reading registers at $C0D0–$C0D3: 

export class WebSensorCard implements IPeripheralCard {
  public readonly name = "Ultra IoT Sensor Card";
  public readonly slot = 5;
  public readonly description = "REST API telemetry bridge for 65C02 programs";
  private currentTemperature = 72; // Fahrenheit

  constructor() {
    // Poll live temperature every 60 seconds
    setInterval(async () => {
      try {
        const res = await fetch("https://api.weather.gov/gridpoints/TOP/31,80/forecast");
        const data = await res.json();
        this.currentTemperature = data.properties.periods[0].temperature;
      } catch (e) { /* fallback default */ }
    }, 60000);
  }

  public ioRead(offset: number): number {
    if (offset === 0x00) return this.currentTemperature & 0xFF; // Read temp via $C0D0
    return 0x00;
  }

  public ioWrite(offset: number, value: number): void {}
  public romRead(offset: number): number { return 0x60; }
  public reset(): void {}
}
Official Architecture Recommendations
1. Dynamic Slot Manager Registry

Maintain a central SlotManager that manages an array of 7 IPeripheralCard | null slots. The MMU dispatches $C080–$C0FF and $C100–$C7FF dynamically to whichever card is plugged in!

2. In-Browser "Custom Card Studio"

Provide a dedicated tab in the "Under the Hood" workbench where users can write or paste custom JavaScript card classes, hit "Plug into Slot 4", and immediately run 65C02 assembly or BASIC code interacting with their new card!
