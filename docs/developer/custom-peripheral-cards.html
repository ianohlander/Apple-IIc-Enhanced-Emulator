Exhaustive I/O Usage Guide for Every Peripheral Card

How to command, read, and connect each card from BASIC, 65C02 Assembly, C# and Java

🖨️ 1. Apple ImageWriter II & Dot Matrix Printer (Slot 1)
Serial I/O: $C090

What It Does: Redirects all character output from the screen to a virtual continuous tractor-feed dot matrix printer. The emulator captures all transmitted bytes into a live paper buffer in the Slot & Card Studio with 1-click text copying and file downloads.

How to Use from Applesoft BASIC: 
10 PR#1 : REM Redirect screen output to Slot 1 Printer
20 PRINT "=================================================="
30 PRINT "      APPLE //c ULTRA BUSINESS SALES REPORT       "
40 PRINT "=================================================="
50 PRINT "ITEM: 65C02 WORKSTATION ....... $1,295.00"
60 PRINT "ITEM: 32MB SMARTPORT HD ........ $499.00"
70 PRINT "ITEM: MOCKINGBOARD STEREO ...... $149.00"
80 PRINT "--------------------------------------------------"
90 PRINT "TOTAL:                          $1,943.00"
100 PR#0 : REM Restore output back to CRT screen
How to Use from Modern C# .NET: 
using System;
using Apple2.Ultra;

public class PrinterApp {
    public static void Main() {
        ApplePrinter.SetSlot(1);
        ApplePrinter.WriteLine("C# AOT COMPILED PRINTOUT");
        ApplePrinter.WriteLine("DATE: " + DateTime.Now.ToShortDateString());
        ApplePrinter.FormFeed();
        ApplePrinter.ResetToScreen();
    }
}
🎹 2. Passport & Web MIDI Master Card (Slot 2)
6850 ACIA: $C0A0

What It Does: Connects the Apple II's serial ACIA controller directly to the browser's Web MIDI API. Any 65C02 MIDI sequencing software (like *Passport Master Tracks* or custom C# sound routines) sends standard 31.25 kBaud MIDI note commands that play directly through your connected physical USB synthesizers, digital pianos, or DAW software (Ableton, Logic, Reaper).

65C02 Assembly MIDI Note-On Transmission Routine: 
; --- SEND MIDI NOTE-ON: Note $3C (Middle C), Velocity $7F ---
MIDI_NOTE_ON:
    LDA #$90        ; MIDI Status Byte: Note-On, Channel 1
    JSR MIDI_SEND
    LDA #$3C        ; MIDI Data Byte 1: Pitch 60 (Middle C)
    JSR MIDI_SEND
    LDA #$7F        ; MIDI Data Byte 2: Velocity 127 (Max Volume)
    JSR MIDI_SEND
    RTS

MIDI_SEND:
    STA $C0A1       ; Transmit byte to Slot 2 ACIA Data Register ($C0A1)
    RTS
⏰ 3. Thunderclock Plus Real-Time Clock (Slot 4)
ProDOS Driver: $C400

What It Does: Supplies the exact local time and date from your host PC/Mac directly to ProDOS. When ProDOS creates or modifies files on the 32MB hard disk, it automatically stamps them with the true real-world timestamp!

Reading Date/Time Registers Directly in BASIC: 
10 HR = PEEK(49346) : MIN = PEEK(49345) : SEC = PEEK(49344)
20 MO = PEEK(49348) : DAY = PEEK(49347) : YR  = PEEK(49349)
30 PRINT "CURRENT TIME: "; HR; ":"; MIN; ":"; SEC
40 PRINT "CURRENT DATE: "; MO; "/"; DAY; "/20"; YR
🔊 4. Sweet Micro Mockingboard Stereo Sound Synthesizer (Slot 4/5)
6522 VIAs: $C0C0–$C0CF

What It Does: Emulates two General Instrument AY-3-8910 Programmable Sound Generator (PSG) chips interfaced through dual 6522 VIAs. Delivers 6 simultaneous musical tone channels, 2 pseudo-random noise generators, and 16-bit hardware envelope modulation.

Writing a Tone in 65C02 Assembly: 
; --- PLAY 440 HZ (A4) ON MOCKINGBOARD CHANNEL A ---
    LDA #$00        ; Register 0: Tone Fine Tune
    STA $C0C0       ; Latch Register 0 on VIA B
    LDA #$71        ; Divisor Low Byte ($71 = 440 Hz)
    STA $C0C4       ; Write Data to VIA A
    LDA #$08        ; Register 8: Channel A Amplitude
    STA $C0C0
    LDA #$0F        ; Volume 15 (Max)
    STA $C0C4
    RTS
🌐 5. Uthernet W5100 TCP/IP Network Card (Slot 5)
WIZnet I/O: $C0B0–$C0BF

What It Does: Bridges the 65C02 CPU to the internet via hardware WIZnet W5100 TCP/IP stack. Used by retro web browsers (Contiki OS), IRC chat clients, telnet BBS terminals, and modern C# HTTP clients.

Sending an HTTP GET Request in C#: 
using System;
using Apple2.Ultra;

public class WebClient {
    public static void Main() {
        AppleNetwork.InitEthernet(slot: 5);
        string response = AppleNetwork.HttpGet("http://api.weather.gov/status");
        Console.WriteLine("SERVER RESPONSE: " + response);
    }
}

Tutorial: Creating Your Own Custom Card in JavaScript

Write custom hardware simulations in 10 lines of code and plug them into Slot 3

You can write a complete custom peripheral card directly in the browser's Slot & Card Studio tab without rebuilding the emulator. Follow this 3-step tutorial to build a Live Cryptocurrency / Stock Ticker Card:

Step 1: Write the Card JavaScript Logic in the Sandbox 
card.bitcoinPrice = 95000;

// Fetch live price every 30 seconds
setInterval(async () => {
  try {
    const res = await fetch("https://api.coindesk.com/v1/bpi/currentprice.json");
    const data = await res.json();
    card.bitcoinPrice = Math.floor(data.bpi.USD.rate_float);
  } catch (e) {}
}, 30000);

// Respond to 65C02 register reads at $C0B0 ($C080 + Slot 3)
card.onReadHandler = (offset) => {
  if (offset === 0x00) return card.bitcoinPrice & 0xFF;         // Low byte
  if (offset === 0x01) return (card.bitcoinPrice >> 8) & 0xFF;  // Mid byte
  if (offset === 0x02) return (card.bitcoinPrice >> 16) & 0xFF; // High byte
  return 0x00;
};
Step 2: Read Live Data from Applesoft BASIC 
10 LOW = PEEK(49328) : MID = PEEK(49329) : HIGH = PEEK(49330)
20 PRICE = LOW + MID * 256 + HIGH * 65536
30 PRINT "LIVE BITCOIN PRICE: $"; PRICE
40 GOTO 10
