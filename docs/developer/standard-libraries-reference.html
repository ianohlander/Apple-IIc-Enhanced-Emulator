1. Architectural Philosophy: Pure Standard Runtimes vs Optional Hardware APIs

CORE DESIGN PRINCIPLE Zero Platform-Lock-In

Write Standard Modern Code Without Proprietary Imports

The 6502 Ultra is engineered so that developers can write and compile pure, standard C# .NET Core and Java applications using standard namespaces (System, System.Collections.Generic, java.lang, java.util) without requiring any proprietary platform-specific packages or imports.

The Apple-specific packages (Apple2.Ultra and apple2.hardware) are purely optional low-level hardware abstraction layers. They are provided for developers who specifically want direct, explicit access to vintage retro hardware features—such as Double Hi-Res 560×192 graphics switches ($C050, $C057, $C05F), analog game paddle timers ($C064), and Mockingboard Dual AY-3-8910 6-voice programmable sound chips.

Mode A: Pure Standard Application Mode

  • Imports standard namespaces only: using System; using System.Collections.Generic; or import java.util.ArrayList;.
  • Console.WriteLine() and System.out.println() automatically lower to Apple ROM character output ($FDED [COUT]).
  • Collections like List<T> and ArrayList manage dynamic heap buffers in Auxiliary RAM.
  • 100% portable code: same source can compile on modern PC, Linux, macOS, and native 65C02 silicon.

Mode B: Hardware-Enhanced Mode (Optional)

  • Optionally imports Apple2.Ultra or apple2.hardware.
  • Directly controls 560×192 16-color Double Hi-Res graphics rasterizers.
  • Reads physical analog game paddles and mouse coordinates ($C064/$C065).
  • Programs the Slot 4 Mockingboard dual AY-3-8910 sound generator (6 polyphonic voices).

2. .NET Core Standard Class Library Reference

The C# Ahead-of-Time compiler natively supports the following standard .NET Core namespaces and types:

Namespace: System • Class: Console

Provides standard character stream I/O for text and terminal applications.

Method Signature Description 65C02 Silicon Lowering Behavior
Console.Write(string value) Outputs a string to the screen. Converts chars to high-bit ASCII (ch | 0x80) and loops LDA #$XX → JSR $FDED [COUT].
Console.WriteLine(string value) Outputs a string followed by a newline. Executes string COUT loop, followed by JSR $FD8E [CROUT] (Carriage Return).
Console.WriteLine(int value) Converts integer to decimal string and outputs. Calls 16-bit binary-to-decimal ASCII conversion subroutine in Zero Page, then invokes COUT.
Console.Clear() Clears the text screen and resets cursor. Calls Apple ROM routine $FC58 [HOME] to clear text buffer and reset row/col to (0,0).

Namespace: System • Class: Math

Provides common mathematical constants and functions.

Member Signature Description 65C02 Silicon Lowering Behavior
Math.Abs(int val) Returns the absolute value of an integer. Tests sign bit with BPL; if negative, negates using two's complement (EOR #$FF + INC).
Math.Max(int a, int b) Returns the larger of two 16-bit integers. Performs 16-bit Zero Page comparison: SEC → LDA a → SBC b → BMI return_b.
Math.Min(int a, int b) Returns the smaller of two 16-bit integers. Performs 16-bit Zero Page comparison: SEC → LDA a → SBC b → BPL return_b.

Namespace: System.Collections.Generic • Class: List<T>

Provides dynamically resizing generic array collections.

Member Description 65C02 Silicon Lowering Behavior
void Add(T item) Appends an item to the end of the collection. Stores item pointer into heap table at base + (size * 2); increments size counter.
int Count Gets the number of elements contained in the list. Reads 16-bit integer at struct offset +2.
T this[int index] Gets or sets the element at the specified index. Computes base + (index * 2) using 16-bit shift (ASL) and loads 16-bit pointer.

3. Java Standard Library (JDK 17) Reference

The Java Ahead-of-Time compiler natively supports the following standard Java packages and classes:

Provides resizable-array implementation of the List interface.

E get(int index) Returns element at index. Calculates pointer offset using 16-bit shift (ASL) and loads reference.
int size() Returns number of elements in list. Loads 16-bit integer from object header offset +2.

4. C# (.NET) & Java Hardware Object SDK API Reference

C# Namespace: Ultra.Hardware • Java Package: ultra.hardware Zero Overhead Native AOT Lowering

For developers building games, graphic demos, sound engines, network drivers, and peripheral interfaces, the 6502 Ultra Hardware SDK exposes 11 specialized hardware abstraction classes. Each method call directly lowers during compilation into inline 65C02 memory-mapped I/O (MMIO) instructions (e.g. STA $C050, LDA $C000, JSR $C700) with zero runtime interpreter overhead.

1. UltraVideo (Graphics & Text VRAM Controller)

C#: Ultra.Hardware.UltraVideo • Java: ultra.hardware.UltraVideo

Controls 40/80 column text screens, Hi-Res Page 1/2 graphics (280×192), and Double Hi-Res 16-color composite graphics (560×192).

Method Signature Parameters & Return 65C02 MMIO / Action
SetDoubleHiRes(bool enable) enable: true for 560×192 DHGR, false for TEXT Strobes STA $C050 (Graphics), STA $C057 (Hi-Res), STA $C00D (80-Col), STA $C05F (DHR-On).
SetTextMode(bool enable) enable: true for 24-row text mode Strobes STA $C051 (Text ON), STA $C05E (DHR OFF).
DrawPixel(int x, int y, int color) x ∈ [0..559], y ∈ [0..191], color ∈ [0..15] Computes scanline base in Main/Aux VRAM ($2000/$4000) and writes 7-pixel packed nibble.
DrawLine(int x0, int y0, int x1, int y1, int color) Line endpoints and 16-color DHGR composite palette index Fast Zero Page Bresenham rasterizer loop plotting into 8KB Video RAM.
ClearScreen(int color) color: solid color or 0 for black Fills 8,192 bytes of Main & Aux Page 1 VRAM ($2000–$3FFF) using 16-bit unrolled store.

2. UltraSound (1-Bit Motherboard Speaker)

C#: Ultra.Hardware.UltraSound • Java: ultra.hardware.UltraSound

Direct control over the physical 1-bit speaker cone flip-flop at softswitch $C030 (decimal 49200).

Method Signature Parameters & Return 65C02 MMIO / Action
Click() None • void Executes single BIT $C030 to toggle speaker cone state.
Beep(int frequencyHz, int durationMs) frequencyHz (pitch), durationMs (duration) Cycles $C030 toggle in timed cycle loop calibrated for 1.02 MHz or 50 MHz clock.

3. MockingAudio (Slot 4 Dual AY-3-8910 6-Voice PSG)

C#: Ultra.Hardware.MockingAudio • Java: ultra.hardware.MockingAudio

Full polyphonic chiptune sound synthesis via dual General Instrument AY-3-8910 sound chips mapped through 6522 VIAs in Slot 4.

Method Signature Parameters & Return 65C02 MMIO / Action
SetTone(int voice, int frequencyHz) voice ∈ [0..5], frequencyHz ∈ [20..20000] Writes 12-bit tone period divider into PSG registers R0/R1, R2/R3, or R4/R5 via VIA port $C0C0.
SetNoisePeriod(int chip, int period) chip ∈ [0..1], period ∈ [0..31] (5-bit) Writes 5-bit LFSR noise generator period to register R6.
SetMixer(int chip, int mixerMask) mixerMask (bits 0-2 tone enable, 3-5 noise enable) Writes I/O mixer control register R7 (active-low bitmask).
SetVolume(int voice, int volume, bool envelope) voice ∈ [0..5], volume ∈ [0..15], envelope flag Writes 4-bit fixed amplitude or 5-bit envelope mode flag to amplitude registers R8, R9, R10.
MuteAll() None • void Zeros all 16 PSG registers across both sound chips in Slot 4.

4. DotMatrixPrinter (Slot 1 Tractor-Feed Printer)

C#: Ultra.Hardware.DotMatrixPrinter • Java: ultra.hardware.DotMatrixPrinter

Interface to the continuous 9-pin dot-matrix tractor-feed printer in Slot 1 (compatible with ImageWriter II / Centronics protocols).

Method Signature Parameters & Return 65C02 MMIO / Action
PrintString(string text) text: ASCII string content Directs character byte stream to Slot 1 Centronics strobe register ($C090).
FormFeed() None • void Sends Form Feed control byte (0x0C / ASCII 12) to advance to the next perforation fold.
LineFeed() None • void Sends Carriage Return + Line Feed (0x0D, 0x0A) to advance paper one platen line.
SetCondensed(bool enable) enable: true for 17.16 CPI condensed mode Transmits ESC sequence ESC Q (condensed font) or ESC N (standard 10 CPI).

5. MidiMaster (Slot 2 31.25 kBaud Web MIDI Interface)

C#: Ultra.Hardware.MidiMaster • Java: ultra.hardware.MidiMaster

Transmits standard MIDI 1.0 serial commands through the 6850 ACIA interface in Slot 2 to connected Web MIDI synthesizers and hardware instruments.

Method Signature Parameters & Return 65C02 MMIO / Action
SendNoteOn(int channel, int noteNumber, int velocity) channel ∈ [0..15], note ∈ [0..127], vel ∈ [0..127] Transmits 3-byte MIDI packet (0x90|channel, note, velocity) via ACIA at $C0A0.
SendNoteOff(int channel, int noteNumber) channel ∈ [0..15], note ∈ [0..127] Transmits 3-byte MIDI packet (0x80|channel, note, 0x00).
SendProgramChange(int channel, int programId) channel ∈ [0..15], programId ∈ [0..127] Transmits 2-byte MIDI program patch change (0xC0|channel, programId).

6. ProDosClock (Slot 4 / Host RTC Calendar)

C#: Ultra.Hardware.ProDosClock • Java: ultra.hardware.ProDosClock

Reads host system real-time clock and calendar values conforming to the ProDOS standard clock driver format ($BF90–$BF93).

Method Signature Parameters & Return 65C02 MMIO / Action
GetDateTime() Returns DateTime (C#) or Date (Java) Reads 4-byte packed ProDOS clock buffer: year/month at $BF90, day at $BF91, hour at $BF92, minute at $BF93.
GetTimestampBytes() Returns byte[4] Copies the raw 4-byte ProDOS timestamp array directly into user memory buffer.

7. Uthernet (Slot 3 10BASE-T Ethernet Controller)

C#: Ultra.Hardware.Uthernet • Java: ultra.hardware.Uthernet

CS8900A 10Mbps Ethernet NIC interface in Slot 3 with bridge to host WebSockets / WebRTC network tunnels.

Method Signature Parameters & Return 65C02 MMIO / Action
Connect(string host, int port) host (IP or domain), port ∈ [1..65535] • bool Initializes CS8900A packet buffer at $C0B0 and begins TCP 3-way handshake.
Send(byte[] buffer, int length) buffer (payload), length • int bytes sent Streams packet frames into NIC transmit FIFO at $C0B4.
Receive(byte[] buffer) buffer (destination) • int bytes received Reads incoming packet frame from receive buffer register $C0B0.

8. StorageCore (32MB SmartPort HD & Dual Floppy Controller)

C#: Ultra.Hardware.StorageCore • Java: ultra.hardware.StorageCore

High-speed mass storage block I/O driver (Slot 7 SmartPort 32MB HD) and Disk II dual-drive floppy controller (Slot 6 Drive 1 / Drive 2).

Method Signature Parameters & Return 65C02 MMIO / Action
ReadBlock(int unit, int blockNum) unit (e.g. $70 for /HD), blockNum ∈ [0..65535] • byte[512] Executes ProDOS MLI READ_BLOCK driver jump at $C700 to read 512-byte block into RAM.
WriteBlock(int unit, int blockNum, byte[] data) unit, blockNum, data ∈ byte[512] • bool Executes ProDOS MLI WRITE_BLOCK driver jump at $C700 to commit 512 bytes to storage.
SelectFloppyDrive(int driveNumber) driveNumber: 1 (Upper Drive) or 2 (Lower Drive) Strobes $C0EA (Drive 1 motor/head) or $C0EB (Drive 2 motor/head) in Slot 6.

9. UltraMemory (MMU Banking & Slinky 16MB RAM)

C#: Ultra.Hardware.UltraMemory • Java: ultra.hardware.UltraMemory

Manages Zero Page / Stack redirection (ALTZP), Auxiliary 128KB banking, Language Card write-enable protection, and 16MB Slinky streaming.

Method Signature Parameters & Return 65C02 MMIO / Action
SetSlinkyAddress(int address24) address24 ∈ [0..16777215] (24-bit pointer) Writes Low ($C071), Mid ($C072), and High ($C073) pointer bytes to Slinky port.
ReadSlinkyByte() Returns byte • Auto-increments 24-bit address Executes LDA $C070 (auto-increments 24-bit pointer after read).
WriteSlinkyByte(byte val) val: 8-bit byte • Auto-increments address Executes STA $C070 (auto-increments 24-bit pointer after write).
SetAltZeroPage(bool enable) enable: true for Aux Zero Page/Stack ($0000–$01FF) Strobes STA $C009 (ALTZP ON) or STA $C008 (ALTZP OFF).

10. UltraSystem (Paddles, Mouse, Keyboard & Turbo Clock)

C#: Ultra.Hardware.UltraSystem • Java: ultra.hardware.UltraSystem

Reads analog game paddles, mouse coordinates, keyboard matrix strobes ($C000/$C010), and switches CPU clock frequency.

Method Signature Parameters & Return 65C02 MMIO / Action
ReadPaddle(int paddleIndex) paddleIndex ∈ [0..3] • Returns int ∈ [0..255] Triggers $C070 timer strobe and counts NE558 discharge cycles at $C064–$C067.
GetMouseButton(int buttonIndex) buttonIndex ∈ [0..2] • Returns bool Reads pushbutton 0 ($C061 Open-Apple), pushbutton 1 ($C062 Solid-Apple), or PB2 ($C063).
ReadKey() Returns char • Clears strobe register Polls bit 7 of $C000; when set, extracts ASCII char and strobes $C010 to reset buffer.
SetCpuClockSpeed(double mhz) mhz ∈ {1.02, 2.80, 8.00, 50.0} Configures hardware cycle budget governor to throttle or turbocharge 65C02 execution.

11. SlotBus (Direct Generic Peripheral Slot I/O)

C#: Ultra.Hardware.SlotBus • Java: ultra.hardware.SlotBus

Low-level generic I/O bus interface allowing any custom user-scripted JavaScript card in Slots 1–7 to be controlled from compiled C# or Java code.

Method Signature Parameters & Return 65C02 MMIO / Action
PeekRegister(int slot, int registerOffset) slot ∈ [1..7], offset ∈ [0..15] • Returns byte Executes LDA $C080 + (slot * $10) + offset and returns 8-bit hardware state byte.
PokeRegister(int slot, int registerOffset, byte value) slot ∈ [1..7], offset ∈ [0..15], value ∈ byte Executes STA $C080 + (slot * $10) + offset to trigger hardware actuator/register.

5. Side-by-Side Application Comparison Cookbook

Standard C# App (Zero Apple Imports)

using System;
using System.Collections.Generic;

namespace PureDotNetApp
{
    public class Program
    {
        public static void Main(string[] args)
        {
            Console.WriteLine("HELLO FROM STANDARD C#!");
            List<string> items = new List<string>();
            items.Add("CPU: 65C02 (50 MHz)");
            items.Add("RAM: 128KB EXPANDED");
            for (int i = 0; i < items.Count; i++)
            {
                Console.WriteLine("ITEM " + (i+1) + ": " + items[i]);
            }
            int result = Math.Max(10, 100);
            Console.WriteLine("RESULT: " + result);
        }
    }
}

Standard Java App (Zero Apple Imports)

import java.util.ArrayList;

public class PureJavaApp
{
    public static void main(String[] args)
    {
        System.out.println("HELLO FROM STANDARD JAVA!");
        ArrayList<String> list = new ArrayList<>();
        list.add("PURE OBJECT RUNTIME");
        list.add("ZERO PAGE REGISTERS");
        for (int i = 0; i < list.size(); i++)
        {
            System.out.println("ENTRY " + (i+1) + ": " + list.get(i));
        }
        int calc = Math.max(10, 50) + Math.abs(-42);
        System.out.println("RESULT: " + calc);
    }
}
