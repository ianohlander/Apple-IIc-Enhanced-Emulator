2. How to Verify Watermarks

1. Live Console Easter Egg: Open the emulator, type CREDITS or COPYRIGHT at the ] prompt, and press Return.

2. Memory Hex Viewer: In the Under the Hood Workbench, inspect memory at $03F0 or $FFF0 to view the ASCII signature.

3. CPU Debugger Disassembly: Compile any C# or Java program in the Modern Code Studio and inspect the header comments in the 65C02 machine code disassembly panel.

4. View Page Source: Right-click any documentation page and select "View Page Source" to inspect the <head> metadata tags and comment watermarks.
