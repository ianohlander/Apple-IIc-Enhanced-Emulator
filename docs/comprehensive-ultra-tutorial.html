Chapter 1: 65C02 Silicon Architecture & Memory Multiplexing

Registers, addressing modes, 128KB MMU banking, and Slinky 1MB expansion

1.1 Microprocessor Register Architecture & CMOS Extensions

The WDC 65C02 CMOS microprocessor is an 8-bit CPU featuring a 16-bit address bus ($0000–$FFFF). It contains six internal registers:

Accumulator (A) [8-bit] Primary arithmetic, logical, and memory transfer register.
Index X (X) [8-bit] Loop counter, indexed addressing ($addr,X), and stack pointer transfer.
Index Y (Y) [8-bit] Indirect indexed pointer traversal ($($zp),Y) and multi-byte operations.
Stack Pointer (SP) [8-bit] Points to descending hardware stack in page 1 ($0100–$01FF).
Program Counter (PC) [16-bit] Directs instruction fetch across the 64KB physical address space.
Processor Status (P) [8-bit] Flags: N (Negative), V (Overflow), B (Break), D (Decimal), I (IRQ), Z (Zero), C (Carry).

1.2 Memory Management Unit (MMU) & Softswitch Architecture

The Apple //c expands the physical address space beyond 64KB using bank-switched auxiliary memory. All banking is controlled by reading or writing dedicated I/O softswitches in page $C0:

Softswitch Hex Address Read / Write Function Subsystem Affected
80STOREOFF $C000 Write: Disable 80-column page switching Video RAM Mapping
80STOREON $C001 Write: Enable PAGE2 to switch Main/Aux Video RAM Video RAM Mapping
RAMRDOFF / ON $C002 / $C003 Write: Read from Main RAM ($0200–$BFFF) vs Aux RAM Memory Subsystem
RAMWRTOFF / ON $C004 / $C005 Write: Write to Main RAM ($0200–$BFFF) vs Aux RAM Memory Subsystem
ALTZPOFF / ON $C008 / $C009 Write: Switch Zero Page ($0000–$00FF) & Stack ($0100–$01FF) CPU Core Subsystem
SLINKY DATA $C073 Read/Write: 1MB Auto-incrementing RAM port Expansion Storage

DIAGRAM 2.1: DUAL-PHASE CLOCK & ZERO-CONTENTION DRAM REFRESH SHARING 14.31818 MHz Master Oscillator $ ightarrow$ 1.023 MHz Symmetrical Clock Cycles
100% Contention-Free

Theoretical Principle: 1970s Dynamic RAM (DRAM) relied on microscopic capacitor charges that decayed in under 2 milliseconds, requiring 128 rows to be continuously addressed to prevent data loss. By interleaving Video scanlines to cycle through the DRAM row counter during $Phi_0$ while the CPU executes during $Phi_1$, Steve Wozniak achieved 100% contention-free memory access and eliminated expensive external refresh ICs.

3.1 Hardware Sound Synthesis Foundations

1-Bit Speaker Cone ($C030 / 49200)

Every memory read or write to $C030 pulses the speaker cone. Frequency is dictated by cycle delays in CPU assembly loops:

$$f = rac{1,023,000}{2 imes ext{Delay Cycles}}$$

6 independent hardware tone generators with 12-bit period registers ($R0–R5$), 5-bit white noise ($R6$), and 16-bit envelope generators:

Chapter 5: Custom ROM Creation & Firmware Engineering

Linking 65C02 hardware interrupt vectors ($FFFA–$FFFF) and writing custom bootloaders

5.1 32KB System ROM Vector Table Structure

When the 65C02 CPU powers on or resets, it fetches the 16-bit address stored at $FFFC–$FFFD and begins execution: 

.ORG $FFFA
        .WORD NMI_SERVICE   ; $FFFA-$FFFB: Non-Maskable Interrupt
        .WORD COLD_BOOT     ; $FFFC-$FFFD: Cold Reset Vector (Power-Up)
        .WORD IRQ_SERVICE   ; $FFFE-$FFFF: Maskable Interrupt / BRK

COLD_BOOT:
        SEI                 ; Disable interrupts
        CLD                 ; Clear decimal mode
        LDX #$FF
        TXS                 ; Set stack pointer to $01FF
        STA $C051           ; TXTSET (Text Mode)
        STA $C054           ; PAGE1 (Page 1)
        STA $C052           ; MIXCLR (Full screen text)
        JSR $FC58           ; HOME (Clear VRAM $0400-$07FF)
        JMP $2000           ; Jump to Custom Operating System!
