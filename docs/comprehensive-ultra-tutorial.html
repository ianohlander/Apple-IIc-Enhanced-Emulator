System Architecture: 1984 Silicon vs. Ultra Enhancements

Memory map partitioning, bank switching, and hardware accelerators

The 64KB Main vs. 64KB Aux Banking Model

The Apple //c addresses memory via a 16-bit bus ($0000–$FFFF). To support 128KB of RAM, the hardware uses softswitch-controlled multiplexers:

Main 64KB RAM Bank ($C008 ALTZPOFF)
  • $0000–$00FF: Zero Page (CPU direct addressing & pointers)
  • $0100–$01FF: Hardware Stack ($01FF down to $0100)
  • $0400–$07FF: Text Page 1 / Lo-Res Screen (40 columns)
  • $0801–$95FF: Applesoft BASIC Program Storage
  • $2000–$3FFF: Hi-Res Page 1 Framebuffer (8,192 bytes)
  • $D000–$FFFF: Banked Language Card (RAM/ROM)
Auxiliary 64KB RAM Bank ($C009 ALTZPON)
  • $0000–$00FF: Aux Zero Page (via softswitch ALTZP)
  • $0100–$01FF: Aux Hardware Stack
  • $0400–$07FF: 80-Column Text Odd Columns (via 80COL)
  • $2000–$3FFF: Double Hi-Res Aux Byte Interleave (560x192)
  • $D000–$FFFF: Aux Language Card Extended Storage

The Video & Graphics Pipeline: Scanline Mathematics

Understanding DRAM refresh sharing, 3-tier address interleaving, and color phase shifting

Why Video Memory is Interleaved (The Woz Hardware Optimization)

In 1977, dynamic RAM (DRAM) required refresh pulses every 2ms across 128 rows. To eliminate dedicated refresh chips and save manufacturing costs, Steve Wozniak designed the Apple II video generator to cycle through DRAM row addresses while fetching video pixels.

Because DRAM address counters incremented linearly while scanning CRT raster lines, consecutive scanlines $Y=0, 1, 2dots$ do NOT sit contiguously in memory. Instead, memory is split into 3 vertical boxes of 64 scanlines, each containing 8 groups of 8 lines:

Hi-Res Scanline Base Address Formula: $$\text{Base}(Y) = \$2000 + 1024 \times (Y \bmod 8) + 128 \times (\lfloor Y / 64 \rfloor) + 40 \times (\lfloor (Y \bmod 64) / 8 \rfloor)$$

How 65C02 Machine Code Plots a Pixel

When executing HPLOT X, Y, the CPU calculates:

  1. Scanline Pointer: Computes $\text{Base}(Y)$ into Zero Page pointer $26/$27.
  2. Byte Offset: Divides horizontal coordinate $X$ by 7: Y = X / 7.
  3. Pixel Bit Mask: Computes bit mask: Mask = 1 << (X % 7) (bits 0–6).
  4. Palette Subcarrier Shift (Bit 7): If bit 7 = 0, colors are Green / Purple. If bit 7 = 1, the color subcarrier is delayed $180^\circ$, producing Orange / Blue!
  5. Memory Write: Executes STA ($26),Y to store the pixel byte into VRAM!

Sound Creation: 1-Bit Speaker to 6-Channel Mockingboard

Square wave timing, AY-3-8910 tone divisors, white noise, and arcade sound effects

1-Bit Speaker Toggle ($C030 / 49200) vs. AY-3-8910 Synthesis

1-Bit Speaker Cone ($C030)

Every access to $C030 physically pulses the speaker cone. Frequency is determined by the CPU cycle delay between pulses:

$$f = \frac{1\,023\,000}{2 \times \text{Delay Cycles}}$$
Dual AY-3-8910 Mockingboard PSG

6 independent hardware tone generators with 12-bit period registers ($R0–R5$), 5-bit white noise ($R6$), and 16-bit envelopes:

$$f = \frac{1\,000\,000}{16 \times \text{Period Divisor}}$$

Custom ROM & Firmware Construction

Linking 65C02 hardware interrupt vectors ($FFFA–$FFFF) and writing custom bootloaders

The 32KB System ROM Vector Table

When the 65C02 CPU powers on or resets, it fetches the 16-bit address stored at $FFFC–$FFFD and begins execution. To build custom firmware, you must supply: 

.ORG $FFFA
        .WORD NMI_SERVICE   ; $FFFA-$FFFB: Non-Maskable Interrupt
        .WORD COLD_BOOT     ; $FFFC-$FFFD: Cold Reset Vector (Power-Up)
        .WORD IRQ_SERVICE   ; $FFFE-$FFFF: Maskable Interrupt / BRK

COLD_BOOT:
        SEI                 ; Disable interrupts
        CLD                 ; Clear decimal mode
        LDX #$FF
        TXS                 ; Set stack pointer to $01FF
        STA $C051           ; TXTSET (Text Mode)
        STA $C054           ; PAGE1 (Page 1)
        STA $C052           ; MIXCLR (Full screen text)
        JSR $FC58           ; HOME (Clear VRAM $0400-$07FF)
        JMP $2000           ; Jump to Custom User Operating System!

Zero-Page virtual register allocation ($80–$8F) and zero platform lock-in

Compiling C# .NET Core and Java 17 to Native 65C02 Binary

High-level languages use 32-bit stack frames. The AOT engine maps these to dedicated Zero Page virtual registers: $80–$81 (R0 Accumulator), $82–$83 (R1 Operand), and $84–$85 (R2 Counter).
