Chapter 1: 65C02 Silicon Architecture & Memory Multiplexing

Registers, addressing modes, 128KB MMU banking, and Slinky 1MB expansion

1.1 Microprocessor Register Architecture & CMOS Extensions

The WDC 65C02 CMOS microprocessor is an 8-bit CPU featuring a 16-bit address bus ($0000–$FFFF). It contains six internal registers:

Accumulator (A) [8-bit] Primary arithmetic, logical, and memory transfer register.
Index X (X) [8-bit] Loop counter, indexed addressing ($addr,X), and stack pointer transfer.
Index Y (Y) [8-bit] Indirect indexed pointer traversal ($(zp),Y) and multi-byte operations.
Stack Pointer (SP) [8-bit] Points to descending hardware stack in page 1 ($0100–$01FF).
Program Counter (PC) [16-bit] Directs instruction fetch across the 64KB physical address space.
Processor Status (P) [8-bit] Flags: N (Negative), V (Overflow), B (Break), D (Decimal), I (IRQ), Z (Zero), C (Carry).
CIRCUIT SCHEMATIC 1.1: BISTABLE FEEDBACK LATCH (SRAM) & 1T-1C CHARGE CELL (DRAM) Electronic feedback loop storage vs. Dynamic microscopic capacitor charge storage
Memory Circuit Physics
A. Bistable Feedback Latch (Cross-Coupled Inverter Loop)

Static Storage Principle: The output of INV 1 drives the input of INV 2, whose inverted output continuously reinforces INV 1. This regenerative electrical loop holds $1$ bit of data permanently as long as power is applied.

B. 1T-1C Dynamic Storage Cell (Capacitor Charge Storage)

Dynamic Storage Principle: 1 bit is stored as microscopic charge in capacitor $C$ (~35 femtofarads). Because electrons leak across the silicon substrate within 2 milliseconds, the Apple //c video scanner must cycle through all 128 rows during $Phi_0$ to recharge every capacitor.

1.2 Complete 65C02 Addressing Modes & Memory Traversal

The WDC 65C02 CMOS microprocessor features 16 distinct addressing modes (13 inherited from the original NMOS 6502 plus 3 powerful CMOS architectural enhancements). Mastering addressing modes is essential for cycle-accurate machine language programming:

Addressing Mode Assembly Syntax Bytes Cycles Hardware Bus Operation & Internal Mechanics
1. Implied / Inherent CLC, DEX, RTS 1 2 Target register is hardwired into the opcode. No operand fetch required.
2. Accumulator INC A, ASL A 1 2 Operates directly on the 8-bit Accumulator register. (INC A/DEC A added in 65C02).
3. Immediate LDA #$42, LDX #$FF 2 2 Operand is a literal constant byte stored in the byte immediately following the opcode.
4. Zero Page LDA $80, STZ $50 2 3 Fetches 8-bit address from operand; high address byte is hardwired to $00 ($0000–$00FF).
5. Zero Page,X LDA $80,X, STZ $20,X 2 4 Adds Index X to 8-bit Zero Page address with 8-bit wraparound (stays inside Zero Page).
6. Zero Page,Y LDX $80,Y, STX $10,Y 2 4 Adds Index Y to Zero Page address with wraparound. Used specifically with LDX and STX.
7. Absolute LDA $2000, STA $C030 3 4 Full 16-bit physical memory address specified in Little-Endian format (Low Byte, High Byte).
8. Absolute,X LDA $0400,X, STA $2000,X 3 4–5 Adds Index X to full 16-bit address. Takes +1 cycle (5 total) if a 256-byte page boundary is crossed or on write.
9. Absolute,Y LDA $0400,Y, STA $2000,Y 3 4–5 Adds Index Y to full 16-bit address. Takes +1 cycle (5 total) on page boundary crossing or write operations.
10. Relative (Branches) BNE -10, BRA +$06 2 2–4 Signed 8-bit two's complement displacement (-128 to +127 bytes from PC+2). (BRA added in 65C02).
11. Absolute Indirect JMP ($FFFC) 3 5 Fetches effective target address from the 16-bit pointer stored at memory location. (6502 page-wrap bug fixed in 65C02!).
12. Indexed Indirect (,X) LDA ($80,X) 2 6 Pre-indexed: Adds X to Zero Page address, then fetches the 16-bit target address from the table at $(ZP+X).
13. Indirect Indexed (),Y LDA ($26),Y, STA ($80),Y 2 5–6 Post-indexed: Fetches 16-bit base pointer from Zero Page, then adds Y. The foundation of graphics and array loops!
14. ZP Indirect [65C02] LDA ($80), STA ($80) 2 5 65C02 CMOS Addition: Directly dereferences a 16-bit pointer stored in Zero Page without needing Index Y = 0.
15. Abs Indexed Indirect [65C02] JMP ($1000,X) 3 6 65C02 CMOS Addition: Indexed Jump Table Dispatch! Jumps directly to target pointer at $(Address + X*2).
16. Stack Push/Pull [65C02] PHX, PLX, PHY, PLY 1 3–4 65C02 CMOS Addition: Direct single-byte stack pushing/pulling for Index Registers without altering Accumulator.

Chapter 2: The Video Subsystem, DRAM Refresh & Scanline Mathematics

Dual-phase bus multiplexing, 3-tier interleaving, and color artifact phase alignment
DIAGRAM 2.1: DUAL-PHASE CLOCK & ZERO-CONTENTION DRAM REFRESH SHARING 14.31818 MHz Master Oscillator → 1.023 MHz Symmetrical Clock Cycles (978 ns Period)
100% Contention-Free

Theoretical Principle: 1970s Dynamic RAM (DRAM) relied on microscopic capacitor charges that decayed in under 2 milliseconds, requiring 128 rows to be continuously addressed to prevent data loss. By interleaving Video scanlines to cycle through the DRAM row counter during Phase 0 ($Phi_0$) while the CPU executes during Phase 1 ($Phi_1$), Steve Wozniak achieved 100% contention-free memory access and eliminated expensive external refresh ICs.

CIRCUIT SCHEMATIC 2.4: 74LS166 PARALLEL-TO-SERIAL VIDEO SHIFTER & NTSC PHASE DELAY Loads 8-bit RAM byte during Phase 0 → shifts 7 pixel dots at 7.16 MHz dot clock
Video Serializer Circuit

Video Serialization Circuit Flow: Every microsecond during Phase 0 ($Phi_0$), the 74LS166 parallel-in shift register latches 1 byte from VRAM. A 7.16 MHz dot clock pushes out bits 0–6 as serial pulses directly into the NTSC composite generator. If Bit 7 is high, a 74LS74 D-type flip-flop delays the pixel burst by 69.8 ns ($180^circ$ phase shift), altering color artifacting from Green/Purple to Orange/Blue!

3.2 Sound Blaster, Yamaha YM3812 (OPL2) FM Synthesis & 8-Bit Digital DAC

While the Mockingboard utilized primitive square-wave generators, the Sound Blaster / AdLib standard introduced Yamaha YM3812 (OPL2) Frequency Modulation (FM) synthesis and 8-bit PCM Digital Audio (DAC) to 8-bit computing. Rather than simple on/off pulses, FM synthesis modulates the frequency of a carrier sine wave with a modulator operator:

2-Operator Frequency Modulation (FM) Synthesis Formula:
Output(t) = Ac(t) × sin( 2π fc t + Im(t) × sin( 2π fm t ) )

Where fc is the Carrier frequency, fm is the Modulator frequency, and Im(t) is the Modulation Index (envelope amplitude).

5.1 32KB System ROM Vector Table Structure

When the 65C02 CPU powers on or resets, it fetches the 16-bit address stored at $FFFC–$FFFD and begins execution. To build custom firmware, you must supply: 

.ORG $FFFA
        .WORD NMI_SERVICE   ; $FFFA-$FFFB: Non-Maskable Interrupt
        .WORD COLD_BOOT     ; $FFFC-$FFFD: Cold Reset Vector (Power-Up)
        .WORD IRQ_SERVICE   ; $FFFE-$FFFF: Maskable Interrupt / BRK

COLD_BOOT:
        SEI                 ; Disable interrupts
        CLD                 ; Clear decimal mode
        LDX #$FF
        TXS                 ; Set stack pointer to $01FF
        STA $C051           ; TXTSET (Text Mode)
        STA $C054           ; PAGE1 (Page 1)
        STA $C052           ; MIXCLR (Full screen text)
        JSR $FC58           ; HOME (Clear VRAM $0400-$07FF)
        JMP $2000           ; Jump to Custom Operating System!
