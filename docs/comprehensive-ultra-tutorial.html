Chapter 1: 65C02 Silicon Architecture & Memory Multiplexing

Registers, addressing modes, 128KB MMU banking, and Slinky 1MB expansion

1.1 Microprocessor Register Architecture & CMOS Extensions

The WDC 65C02 CMOS microprocessor is an 8-bit CPU featuring a 16-bit address bus ($0000–$FFFF). It contains six internal registers: Accumulator (A), Index X, Index Y, Stack Pointer (SP @ $0100-$01FF), Program Counter (PC), and Processor Status (P: N, V, B, D, I, Z, C).

Accumulator (A) [8-bit] Primary arithmetic, logical, and memory transfer register.
Index X (X) [8-bit] Loop counter, indexed addressing ($addr,X), and stack pointer transfer.
Index Y (Y) [8-bit] Indirect indexed pointer traversal ($(zp),Y) and multi-byte operations.
Stack Pointer (SP) [8-bit] Points to descending hardware stack in page 1 ($0100–$01FF).
Program Counter (PC) [16-bit] Directs instruction fetch across the 64KB physical address space.
Processor Status (P) [8-bit] Flags: N (Negative), V (Overflow), B (Break), D (Decimal), I (IRQ), Z (Zero), C (Carry).
LAB EXERCISE 1.1 Entering the 65C02 System Monitor, Depositing CMOS Instructions & Memory Inspection
💡 What You Are Doing & Why:

In this lab, you will leave Applesoft BASIC and enter the machine's low-level 65C02 System Monitor. The System Monitor is a built-in ROM utility that gives you raw, unmediated access to physical memory ($0000–$FFFF) and CPU execution.

You will deposit a short machine code program into Page 3 user staging RAM ($0300) that exercises the CMOS-exclusive STZ (Store Zero) instruction to clear Zero Page address $06 and absolute address $0800 without altering CPU registers, execute it, and inspect memory to verify the zeroed bytes.

Step-by-Step Instructions:
  1. At the Applesoft BASIC prompt (] █), type CALL -151 and press Return.
    Rationale: Decimal -151 maps to address $FF69 (65536 - 151 = 65385), the standard ROM entry point for the System Monitor. The prompt changes from ] to *.
  2. At the * prompt, type 0300: 64 06 9C 00 08 60 and press Return.
    Rationale: Memory address $0300 is the start of Page 3 user RAM. This deposits 6 machine code bytes into memory.
  3. Type 0300G and press Return.
    Rationale: The G (Go) command sets the CPU Program Counter (PC) to $0300 and executes the routine until RTS returns control to the Monitor.
  4. Type 06.06 and press Return.
    Rationale: The range format START.END inspects memory. Address $0006 now holds $00!
  5. Type 3D0G and press Return.
    Rationale: Jumps to the BASIC warm restart vector at $03D0, safely returning to the Applesoft ] prompt with your program intact.
Terminal Session & Annotated Code Breakdown: 
] CALL -151                     ; Enter 65C02 System Monitor (* prompt)
* 0300: 64 06 9C 00 08 60       ; Deposit Hex Opcodes into Page 3 RAM:
                                ;   $0300: 64 06     -> STZ $06    (Store Zero in Zero Page $06)
                                ;   $0302: 9C 00 08  -> STZ $0800  (Store Zero in Absolute $0800)
                                ;   $0305: 60        -> RTS        (Return from Subroutine to Monitor)
* 0300G                         ; Go: Execute machine code routine at $0300
* 06.06                         ; Inspect Zero Page address $0006
0006: 00                        ; Output: Value at $0006 is 00 (Successfully cleared!)
* 3D0G                          ; Exit Monitor: Jump to $03D0 (Applesoft BASIC warm start)
] █                             ; Returned to Applesoft BASIC prompt

Chapter 2: The Video Subsystem, DRAM Refresh & Scanline Mathematics

Text Page 1/2 ($0400/$0800), Hi-Res ($2000-$3FFF), Double Hi-Res, and scanline interleaving

2.1 Wozniak's Interleaved Video Addressing Derivation

The 6502 Ultra Video Generation circuitry avoids hardware multipliers by sharing the DRAM row counter with video refresh cycles. For scanline Y ∈ [0, 191], the base address Addr(Y) is computed as:

Addr(Y) = Base + (Y % 8) * 1024 + ((Y / 8) % 8) * 128 + (Y / 64) * 40
LAB EXERCISE 2.1 Plotting Hi-Res Scanline Points via Direct VRAM Memory Injection
💡 What You Are Doing & Why:

In 6502 Ultra graphics, High-Resolution Graphics Page 1 occupies 8,192 bytes of memory from $2000 to $3FFF (decimal 8192 to 16383). The video circuitry does not lay scanlines out sequentially in memory; instead, scanlines are interleaved in 8-line boxes.

Writing a byte with all 7 data bits set (255 = binary 11111111) lights up 7 continuous pixels on that horizontal scanline. Because each subsequent sub-scanline within an 8-line box is offset by exactly 1,024 bytes ($0400), looping Y = 0 TO 7 plots a vertical line segment directly in VRAM without calling graphics ROM subroutines!

Step-by-Step Instructions:
  1. Type HGR : HCOLOR=3 and press Return.
    Rationale: HGR triggers video softswitches $C050 (graphics), $C057 (hires), and $C053 (mixed 4-line text), clearing Hi-Res Page 1 to black.
  2. Type FOR Y = 0 TO 7 : POKE 8192 + Y * 1024 + 20, 255 : NEXT Y and press Return.
    Rationale: Directly injects byte 255 into column 20 across scanlines 0 through 7. Observe the solid vertical bar rendered on the CRT!
  3. Type TEXT to return to full 24-row text mode.
Terminal Session & Annotated Code Breakdown:

Chapter 5: Custom ROM Creation & Firmware Engineering

Linking 65C02 hardware interrupt vectors ($FFFA–$FFFF), cold boot initialization, and custom kernel hacking

5.1 32KB System ROM Vector Table Structure ($FFFA–$FFFF)

When the 65C02 microprocessor powers on, receives an interrupt, or resets, the CPU hardware hard-wires instruction fetching to the top 6 bytes of the 16-bit address space. The 16-bit address stored in each vector determines where execution jumps:

NMI Vector ($FFFA–$FFFB) Non-Maskable Interrupt. Jump address when the physical /NMI pin goes low.
RESET Vector ($FFFC–$FFFD) Power-On / Reset. Points to cold boot initialization routine at $F800 (63488).
IRQ / BRK Vector ($FFFE–$FFFF) Interrupt Request / Break. Shared vector for software BRK ($00) and hardware /IRQ.
LAB EXERCISE 5.1 Inspecting the System Reset Vector ($FFFC–$FFFD) via Applesoft PEEK
💡 What You Are Doing & Why:

In 65C02 architecture, 16-bit pointers are stored in little-endian order (Least Significant Byte first at the lower address, Most Significant Byte second at the higher address).

In this lab, you will query the reset vector using Applesoft BASIC PEEK statements. Address $FFFC in decimal is 65532, and $FFFD is 65533. To reconstruct the 16-bit address in decimal, we compute: PEEK(65532) + PEEK(65533) * 256.

Step-by-Step Instructions:
  1. At the Applesoft BASIC prompt (] █), type: 
    ? PEEK(65532) + PEEK(65533) * 256
  2. Press Return.
  3. Observe the output value: 63488.
Mathematical Verification & Address Translation: 
65532 ($FFFC) = $00 (LSB)
65533 ($FFFD) = $F8 (MSB = 248 decimal)
Address = $F800 = (248 * 256) + 0 = 63,488
Result: Successfully verified authentic 6502 Ultra cold boot reset entry vector!

Floppy 6-and-2 GCR, SmartPort 32MB hard disk ($C700 MLI), Slinky 1MB RAM disk, and object-oriented file persistence

8.1 Multi-Tier Storage Topology: Floppy, Hard Disk & RAM Disk

The 65C02 Ultra bridges vintage 140KB magnetic diskettes with modern high-capacity 32MB hard disk volumes and ultra-low latency banked RAM disks:

1. Disk II 5.25" Floppy (Slot 6)

• Capacity: 143,360 Bytes (140 KB)
• Geometry: 35 Tracks × 16 Sectors × 256 Bytes
• Encoding: 6-and-2 GCR (256B user data → 342B disk bytes)
• Head Control: 4-Phase Stepper ($C0EC..$C0EF)
• Driver Entry: JSR $C600 (Boot: PR#6)

2. SmartPort 32MB HD (Slot 7)

• Capacity: 33,554,432 Bytes (32,768 KB)
• Geometry: 65,536 Contiguous 512-Byte Blocks
• Protocol: ProDOS MLI Block Protocol
• Topology: Seedling (≤512B), Sapling (≤128KB), Tree (>128KB)
• Driver Entry: JSR $C700 (Boot: PR#7)

3. Slinky 1MB RAM Disk (Slot 4)

• Capacity: 1,048,576 Bytes (1,024 KB)
• Registers: $C0C8-$C0CA (24-bit Addr), $C0CB (Data R/W)
• Throughput: Zero-latency auto-incrementing DMA
• Volume: /RAM (2,048 ProDOS Blocks)
• Ideal For: High-speed audio streaming & temp caches

LAB EXERCISE 8.5 High-Speed Slinky 1MB RAM Disk Data Streaming & Buffer Paging
💡 What You Are Doing & Why:

The Slinky 1MB Memory Expansion Card exposes 1MB of banked RAM through 4 hardware registers: $C0C8 (Address LSB), $C0C9 (Address MID), $C0CA (Address MSB / Bank), and $C0CB (Data Port). Every read or write to $C0CB automatically increments the 24-bit internal address counter, allowing blazing-fast streaming into VRAM without CPU pointer arithmetic! 

; Slinky Fast DMA Video Streaming Routine ($C0C8-$C0CB)
  LDA #$00 : STA $C0C8   ; Set Slinky Address LSB ($00)
  LDA #$10 : STA $C0C9   ; Set Slinky Address MID ($10 = 4KB offset)
  LDA #$00 : STA $C0CA   ; Set Slinky Bank 0
  LDY #$00
STREAM_LOOP:
  LDA $C0CB              ; Read byte from Slinky (Hardware Auto-Increments!)
  STA $2000,Y            ; Store directly into Hi-Res Page 1 ($2000)
  LDA $C0CB              ; Read next byte
  STA $2100,Y            ; Store into next video page ($2100)
  INY
  BNE STREAM_LOOP        ; Transfer 512 bytes in a single tight loop!
