How to Deploy Publicly While Keeping Your WordPress Site 100% Intact

By deploying to a dedicated subdomain (apple2.ianohlander.com), your primary WordPress website on GoDaddy/Hostinger remains completely safe and untouched. Below are the exact, step-by-step instructions for GitHub Pages Global CDN (Option A, Recommended) and Hostinger VPS Nginx (Option B).

A

Option A: GitHub Pages + Custom Domain (Recommended)

100% Free • Global Fastly CDN • Automated Deploy on Git Push • Zero Server Maintenance

1 Add CNAME Record in Hostinger DNS / GoDaddy
Time: ~2 mins
  1. Log into your Hostinger hPanel (or GoDaddy DNS if your nameservers are managed there).
  2. Go to Domains → ianohlander.com → DNS / Nameservers.
  3. In the Manage DNS records section, add a new record with the following values:
Type Name / Host Points to / Value TTL
CNAME apple2 ianohlander.github.io 300 (or default)

*Note: Entering apple2 automatically creates the subdomain apple2.ianohlander.com.

2 Enable GitHub Pages in Repository Settings
Time: ~1 min
  1. Visit your repository on GitHub: https://github.com/ianohlander/Apple-IIc-Enhanced-Emulator
  2. Click Settings → Pages (on the left sidebar).
  3. Under Build and deployment → Branch, select main and folder / (root) → click Save.
  4. Under Custom domain, type: apple2.ianohlander.com → click Save.
  5. Wait ~5 minutes for DNS check to pass, then check Enforce HTTPS.
✅ That's it! Your site will now be live at https://apple2.ianohlander.com globally!
B

Option B: Hostinger VPS Deployment (Nginx + SSL)

Self-Hosted on your Ubuntu/Debian Hostinger VPS with Nginx

If you want to host the files directly on your Hostinger VPS, follow these 3 commands:

1. Point DNS A-Record to VPS IP:

In Hostinger DNS, add: Type = A, Host = apple2, Points to = [YOUR_VPS_IP].

2. Clone Web Files to /var/www/apple2ultra: 
sudo mkdir -p /var/www/apple2ultra
sudo git clone https://github.com/ianohlander/Apple-IIc-Enhanced-Emulator.git /var/www/apple2ultra
sudo cp /var/www/apple2ultra/deploy/hostinger-nginx.conf /etc/nginx/sites-available/apple2.ianohlander.com
sudo ln -s /etc/nginx/sites-available/apple2.ianohlander.com /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
3. Obtain Free HTTPS Certificate: 
sudo certbot --nginx -d apple2.ianohlander.com
