GoDaddy DNS + Hostinger VPS Architecture apple2.ianohlander.com

How to Host This Application on Your Subdomain Without Risking Your Existing VPS Project

You have ianohlander.com registered on GoDaddy, and a Hostinger VPS currently serving another active project. This guide shows how to deploy apple2.ianohlander.com cleanly without risking downtime, CPU throttling, or configuration conflicts on your existing project.

A

Option A: GoDaddy CNAME → GitHub Pages (Top Recommendation)

100% Free • Global Fastly Edge CDN • Zero VPS Memory/CPU Burden • Automatic Git Deploy

Why this is best for you: Because your Hostinger VPS is already running another application, hosting this static client-side WASM emulator on GitHub Pages completely protects your VPS. If a Hacker News launch drives 100,000 visitors, GitHub Pages' global Fastly CDN handles all traffic with 0ms delay, $0 hosting cost, and zero CPU load on your VPS.
  1. Log into your GoDaddy Account → Domains → ianohlander.com → Manage DNS.
  2. In the DNS Records table, click Add New Record:
Type Name / Host Value / Points to TTL
CNAME apple2 ianohlander.github.io 1/2 Hour (or default)
  1. Click Save.
  2. In your GitHub repo (ianohlander/Apple-IIc-Enhanced-Emulator), go to Settings → Pages.
  3. Under Custom domain, verify it is set to: apple2.ianohlander.com.
  4. Check Enforce HTTPS.
✅ Your application is now live at https://apple2.ianohlander.com globally!
B

Option B: Hostinger VPS Side-by-Side Nginx Virtual Host

Self-hosting on your VPS alongside your existing project using isolated Nginx server blocks

If you prefer keeping everything on your Hostinger VPS, you can host Apple //c Ultra side-by-side with your existing project without port conflicts:

1. Add A-Record in GoDaddy:

In GoDaddy DNS, add: Type = A, Name = apple2, Value = [YOUR_HOSTINGER_VPS_IP].

2. Deploy to /var/www/apple2ultra on VPS: 
sudo mkdir -p /var/www/apple2ultra
sudo git clone https://github.com/ianohlander/Apple-IIc-Enhanced-Emulator.git /var/www/apple2ultra
sudo cp /var/www/apple2ultra/deploy/hostinger-nginx.conf /etc/nginx/sites-available/apple2.ianohlander.com
sudo ln -s /etc/nginx/sites-available/apple2.ianohlander.com /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
3. Enable Free SSL Certificate: 
sudo certbot --nginx -d apple2.ianohlander.com
