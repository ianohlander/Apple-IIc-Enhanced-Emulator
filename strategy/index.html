With zero software installation required, professors can assign homework labs that run in any web browser.

Pillar 5: Legal Architecture, ROM Copyright & Commercialization Safeguards

IP & Compliance
Q1: Aren't there concerns regarding Apple copyright of any Apple II ROMs we are using?

Direct Answer: Yes, original Apple ROM dumps (such as Microsoft/Apple Applesoft BASIC and the 1984 32KB masked system ROMs) remain the intellectual property of Apple Inc. Distributing or selling original Apple binary dumps without a license would infringe their copyright.

✓ How Apple //c Ultra Solves This (100% Clean-Room Architecture):

The built-in default firmware in this emulator (generateDefaultApple2cRom() in src/emulator/roms/defaultRoms.ts) is a 100% clean-room synthesized BIOS written entirely from scratch in TypeScript. It provides standard reset vectors ($FFFC-$FFFD), clear screen routines ($FC58), character I/O ($FDED), and keyboard polling ($FD1B) without containing a single byte of Apple's proprietary 1984 mask ROM code. Furthermore, the Custom ROM Studio enables a "Bring Your Own ROM" (BYOR) workflow for users who dump ROMs from their own physical machines.

Q2: Can the application itself be legally commercialized and monetized?

Direct Answer: Yes. Under landmark US federal court rulings (Sony Computer Entertainment v. Connectix Corp., 203 F.3d 596, and Sony v. Bleem!), writing software that emulates the behavior of hardware (like 6502/65C02 CPUs, ALU logic, video framebuffers, and sound chips) is completely legal.

✓ What You Can Legally Monetize Freely:

  • Your Original Software & Compilers: The C# 10 and Java 17 AOT compilers, 65C02 emulator, and debugger toolchain.
  • Textbooks & Courseware Packs: The 9-chapter Systems Engineering textbook, university lab manuals, and solution keys ($499/dept).
  • Original Games: Retro Breakout, Dungeon Crawler, Raycaster, and new titles created with the SDK.
  • Developer Extensions: VS Code marketplace extensions and profiling tools.
Q3: How do we handle Apple's Trademarks ("Apple", "Apple II", "Apple //c")?

"Apple" and "Apple II" are registered trademarks of Apple Inc. When selling commercial products (like courseware or VS Code extensions), avoid using "Apple" as the standalone brand. Instead, use Nominative Fair Use (e.g. "Ultra 6502 Lab (Apple II Compatible)") and include the standard trademark disclaimer notice (see Legal & IP Guide).
